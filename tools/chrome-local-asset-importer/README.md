# Lingua 网页素材采集 Chrome 扩展

用于扫描当前网页图片和媒体，批量导入 Lingua 统一素材库。

## 安装

扩展没上架 Chrome Web Store，只能开发者模式加载未打包目录，这一步消不掉。
Lingua 的「创作工坊 → 连接器」页面会显示同样三步，并给出本机的绝对路径可一键复制。

1. 打开 Chrome：`chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录：`tools/chrome-local-asset-importer`

装好后点扩展图标、填 Lingua 地址点「连接」，工坊连接器页面就会显示「已连接」。

## 打包分发

    python3 tools/package_connectors.py

产物固定落在 `tools/dist/`：

| 产物 | 用途 |
| --- | --- |
| `lingua-chrome-collector/` | 干净的可加载目录，等价于直接选源目录 |
| `lingua-chrome-collector.zip` | 拷给别人 / 上传 Web Store，`manifest.json` 在包根 |

脚本幂等，源码没变就不重写文件；打包前会拒收 `node_modules` 之类的目录，
并扫一遍文本文件，发现本机绝对路径直接中止。`.crx` 需要签名密钥，做法见
`tools/dist/README.md`。

## 使用

1. 运行 `./start-nexus.sh` 启动 NEXUS 前端与后端服务。
2. 点击浏览器右上角插件图标。
3. 输入 Lingua Web 地址，本机默认 `127.0.0.1:5173`，局域网可填 `192.168.1.10:5173`。
4. 点击「连接」。
5. 可点击图钉按钮打开 Chrome 侧边栏，侧边栏不会因为切换页面而关闭。
6. 在任意网页点击「扫描」，插件会列出当前页面可访问的图片。
7. 勾选图片；智能分类可沿用 Lingua 全局视觉模型，也可选择已启用的 Chat/视觉模型部署，并填写本次分类要求。
8. 可开启「导入后智能分类」，点击「导入所选」。
9. 也可以点「下载到本地」把所选素材直接存到浏览器下载目录——**这一步不需要连接后端**，可当作独立采集工具使用。选多张时会自动打包成一个 zip 压缩包（以「文件夹」命名），单张则直接下原文件。

导入后会进入 Lingua 图片/视频/音频/文件统一素材库，「文件夹」会对应一个素材分组。

## 支持的素材来源

- 普通 `http/https` 图片、视频（由后端下载）。
- `blob:` 资源（如飞书文档）：在网页上下文里读取字节后以 base64 上传。
- `data:` 内联图片、SVG `<image xlink:href>`（如夸克文档整页渲染）。
- 跨域 `<iframe>` 内的素材（扫描与读取均覆盖所有 frame）。
- `<canvas>` 画布内容（如腾讯文档、网页版 PDF、图表）：用 `toDataURL` 导出；若画布被跨域图片污染会抓取失败，属正常现象。
- 勾选「扫描前自动滚动加载」可触发长文档 / 懒加载页面把图片渲染出来再扫描。
- 「截取当前可见画面」按钮：用浏览器合成的屏幕画面截图，适用于**地图 / WebGL / 加密画布**等 `toDataURL` 读出来是黑屏的内容（只截可见视口）。
- **视频**：扫描会收 `<video>`、`source` 以及 `.mp4/.webm/.mov/.m4v/.flv` 直链；后台还会**嗅探网络请求**里通过 XHR/fetch 加载的媒体（DOM 里看不到的），合并进扫描结果。
  - 直链文件（mp4/webm/flv 等）可直接导入下载。
  - 标记为「M3U8 / 流」的是 HLS/DASH 流媒体清单，由"播放列表+大量切片"组成，**本工具不下载合流**，需用专门的下载器处理（清单 URL 已为你列出）。
  - blob/MSE 流媒体（B站/YouTube 等）和 DRM 加密视频（Netflix/会员视频）无法通过直链获取。

## 注意

- DRM 加密视频（Netflix 等）、WebGL/Figma 实时渲染、闭合 shadow DOM 无法抓取。
- 局域网使用时访问 Vite 的 `5173` 端口；后端 `8100` 仍可只监听本机回环。
- 图钉按钮会打开 Chrome 侧边栏；扫描时会读取当前浏览器窗口正在激活的网页标签页。
- 有些网站会限制防盗链，后端下载失败时插件会显示失败数量。
- 智能分类会调用 Lingua 配置中已绑定或本次所选的视觉模型。扩展只保存模型部署 ID，不保存 API Key。
- 弹窗/侧边栏打开时每 45 秒向 `GET /api/studio/connectors/status` 报一次心跳，工坊连接器页面据此显示连接状态。关掉面板心跳就停，页面会转成「未连接」——那只说明现在没在通信，不代表卸载了。
