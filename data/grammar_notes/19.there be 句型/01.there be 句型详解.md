# there be 句型详解

## 1. there 不是「那里」

### 1.1 形式主语 there 与地点副词 there

`there be` 里的 there **没有词义**，它占着主语的位置，真正的主语在 be 后面。

| 句子 | there 的身份 | 主语 |
| --- | --- | --- |
| **There** is a book on the desk. | 形式主语，无词义 | a book |
| The book is over **there**. | 地点副词，意思是「那里」 | The book |
| **There** is a man **there**. | 前者形式主语，后者地点副词 | a man |

> [!danger] 把 there 读成「那里」，主语就找错了
>
> *There are three reasons for this.* 不是「那里有三个原因」，而是「有三个原因」。
> 主语是 `three reasons` 不是 `there`——这一点决定了后面的谓语用单数还是复数，
> 也决定了整句的信息重心落在哪儿。

### 1.2 基本结构

**There + be + 主语 + 地点/时间状语**

| 例句 | 中文 |
| --- | --- |
| There **is** a cat under the table. | 桌子底下有只猫。 |
| There **are** many people in the hall. | 大厅里有很多人。 |
| There **was** no time to explain. | 没时间解释了。 |

---

## 2. 就近一致：be 跟着最近的那个名词

### 2.1 单复数看紧挨着的主语

be 动词的单复数由**紧跟其后的第一个名词**决定，不是由全部主语决定。

| 例句 | be 的形式 | 依据 |
| --- | --- | --- |
| There **is** a book and two pens on the desk. | is | 最近的是 a book（单数） |
| There **are** two pens and a book on the desk. | are | 最近的是 two pens（复数） |
| There **is** some milk and three eggs. | is | 最近的是 some milk（不可数） |

这就是**就近原则**（Proximity Principle），与 `either...or` / `neither...nor` 同一条规则。

### 2.2 不可数名词用单数

| 例句 |
| --- |
| There **is** some water in the glass. |
| There **is** a lot of information about it. |
| There **is** much work to do. |

---

## 3. 时态与情态：变的是 be，不是 there

`there` 位置固定不动，所有变化都发生在 be 上。

| 形式 | 例句 | 中文 |
| --- | --- | --- |
| 一般现在 | There **is / are** ... | 有 |
| 一般过去 | There **was / were** ... | 曾有 |
| 一般将来 | There **will be** ... | 将有 |
| be going to | There **is going to be** ... | 将要有 |
| 现在完成 | There **has / have been** ... | 已经有 |
| 过去完成 | There **had been** ... | 那时已有 |
| 现在进行 | There **is being** ...（罕用） | 正在有 |
| 情态动词 | There **may / must / should be** ... | 可能／一定／应该有 |

| 例句 | 中文 |
| --- | --- |
| There **will be** a meeting tomorrow. | 明天有个会。 |
| There **has been** an accident. | 出事故了。 |
| There **must be** some mistake. | 一定是哪儿弄错了。 |
| There **used to be** a school here. | 这儿以前有所学校。 |

> [!tip] 将来时不是 there will have
>
> `There will be` 里 be 是原形，不能写成 *There will is* 或 *There will have*。
> 情态动词后面同理，一律接 `be`。

## 4. 疑问与否定

### 4.1 疑问句把 be 提到 there 前面

| 陈述 | 疑问 |
| --- | --- |
| There is a problem. | **Is there** a problem? |
| There were many people. | **Were there** many people? |
| There will be a test. | **Will there be** a test? |

回答用 `Yes, there is. / No, there isn't.`，**保留 there**，不换成 it。

### 4.2 否定有两种写法

| 写法 | 例句 | 语气 |
| --- | --- | --- |
| be + not | There **isn't** any milk. | 中性 |
| no + 名词 | There **is no** milk. | 更强调「一点也没有」 |

`not any` 与 `no` 意思接近，`no` 语气更重。**不能两个一起用**：
~~There isn't no milk.~~

### 4.3 反义疑问句用 there

附加部分保留 `there` 作形式主语：

| 例句 |
| --- |
| There is a problem, **isn't there**? |
| There weren't any tickets, **were there**? |

## 5. there be 与 have：不能互换

两者中文都译成「有」，但分工完全不同。

| 结构 | 表达 | 例句 |
| --- | --- | --- |
| **there be** | 某处**存在**某物 | **There is** a book on the desk. |
| **have** | 某人**拥有**某物 | I **have** a book. |

| 正确 | 错误 |
| --- | --- |
| **There are** 50 students in our class. | ~~Our class has 50 students.~~（生硬） |
| I **have** two brothers. | ~~There are two brothers of mine.~~ |

> [!danger] 这是中式英语的高频来源
>
> 中文「我们班有 50 个学生」的「有」是存在不是拥有，所以英语用 there be。
> 反过来「我有两个兄弟」的「有」是拥有，用 have。
> **判据：主语是人且真的「拥有」就用 have，其余的「某处有某物」用 there be。**

---

## 6. there being：非谓语形式

`there be` 也有非谓语形式，用在需要动名词或不定式的位置。

| 形式 | 例句 | 中文 |
| --- | --- | --- |
| **there being** | I didn't know about **there being** a meeting. | 我不知道有个会。 |
| **there being**（独立主格） | **There being** no bus, we walked home. | 没有公交车，我们走回家了。 |
| **there to be** | I expect **there to be** no problem. | 我预计不会有问题。 |

> [!info] 独立主格里的 there being
>
> `There being no bus, we walked home.` 等价于 `As there was no bus, we walked home.`
> 这是分词作状语的一种，逻辑主语是 there —— 读句时把它还原成一个原因状语从句即可。

---

## 7. 变体：不只是 be

`there` 后面可以接其他表示存在或出现的动词，多见于书面语。

| 动词 | 例句 | 中文 |
| --- | --- | --- |
| seem to be | **There seems to be** a misunderstanding. | 好像有点误会。 |
| appear to be | **There appears to be** no way out. | 看来没有出路。 |
| exist | **There exist** several theories. | 存在几种理论。 |
| remain | **There remains** much to be done. | 还有很多事要做。 |
| live | Once **there lived** an old king. | 从前有位老国王。 |

这类句子里 there 仍是形式主语，谓语的单复数照样由后面的真主语决定。
