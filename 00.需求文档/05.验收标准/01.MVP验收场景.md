# MVP 验收场景

> [!info] 口径
>
> 模块级 AC 见各功能需求文档；本文只保留端到端场景与全局门槛。里程碑退出条件见 [MVP 与路线图](../00.产品总览/02.MVP与路线图.md)。

## 1. 端到端场景

### M1 书库精读

1. 上传一本 epub → 60s 内可开始阅读；目录、封面、进度正常。
2. 点任意生词 → 词典字段即时可见；点"AI 解释" → 流式生成语境义；关掉重开同一词 → 直接展示，无新调用。
3. 点任意句 → 译文出现；切换另一个翻译引擎 → 两条结果并列对比；点"语法分析" → 三级结构展示。
4. 开启双语对照 → 从视口开始流式回填；中断后再开 → 从断点继续，已译句不重复计费。
5. 整篇朗读 → 句级高亮跟随；换音色语速 → 下一句生效。
6. 收藏 5 个生词 → 生词本可见，带原句与出处。
7. 断电重启 Compose → 以上全部数据完好。

### M2 语音与视频

8. 自由话题语音对话 10 轮 → 首响 P50 < 1s，随时打断 AI 立即停声；结束后转写与纠错汇总可查。
9. 阅读器内唤起陪读 → 问"当前这句的从句结构" → 回答与所指句一致。
10. 粘贴 YouTube URL → 8 分钟内（10 分钟视频）可点读；点击字幕第 N 句 → 视频跳转该句；字幕点词出卡。
11. 无字幕本地视频 → 自动转写生成字幕 → 双语模式可用。

### M3 学习闭环

12. 书里收藏的词 → 次日复习队列出现，卡片带原句，点出处跳回书中该句并高亮。
13. 考研词表背单词 20 个 → FSRS 排期正确；中断重进队列一致。
14. 词表 CSV 导入 → 预览统计准确、确认后导入、失败行有明细。

## 2. 全局通过条件

1. 完整学习路径可走通：导入内容 → 阅读/观看 → 点词 → 学习 → 收藏 → 复习 → 回跳出处。
2. 主路径没有未解释的无限加载、静默失败或来源混淆（词典/AI/机翻标识清晰）。
3. 所有 AI/翻译产物二次访问零新增调用（缓存命中率可在用量页验证）。
4. 免费档（本地词典、edge-tts、免费翻译）全挂时，学习主链路仍可用（降级可解释）。
5. 单条命令 `docker compose up -d` 从零启动全部服务。
