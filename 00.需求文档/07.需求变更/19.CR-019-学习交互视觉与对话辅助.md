# CR-019 学习交互视觉与对话辅助

- 提出：scholar，2026-09-03
- 状态：基础学习交互、VRM 口语伙伴与网络配置已实现；连续通话声音与人物审美验收待完成
- 影响：视频学习、阅读、词汇、语法、对话、Talk API、Image2 资产

## 1. 决策

1. 播放、逐句导航、字幕、循环、间隔、翻译、推荐回答、查词和收藏使用一套按语义绘制的 Image2 二次元操作图集，不以同一个通用符号代替不同动作。
2. 内置生词本、考试词本和场景词本使用同一套 Image2 二次元封面。封面不写标题，标题和学习状态继续由可访问的 HTML 渲染；未知的用户自建词本保留用户封面或现有回退图。
3. 语法模块五个页签共享固定的顶部页签、内容起点、可用高度、背景和滚动容器。切换页签不得改变页面宽度、顶部位置或浏览器级滚动状态。
4. 对话右栏增加当前 AI 话语翻译、意图提示、三条分级推荐回答及中文含义、可点击单词卡和收藏。辅助结果按当前会话和原句请求，不自动替用户发送。
5. 推荐回答只填入文本会话输入框；实时语音会话提供朗读供跟读，不在未确认时向模型发送。
6. 对话辅助使用现有模型服务和词典能力，不新增第三方依赖；模型不可用时显示明确失败并保留原对话。

## 2. 验收

- 视频学习的两行控制区可以通过图形与文字共同区分播放、逐句、循环和间隔动作，图标按钮具备可访问名称。
- 20 个内置或预置词本显示与语义匹配的统一二次元封面；未知自建词本不会丢失用户封面。
- 语法五个页签切换时，页签栏和内容视口位置保持一致，页面无横向溢出。
- 对话右栏可对最近一条 AI 消息生成中文翻译、意图和恰好三条推荐回答；点击英文单词可查看词义、读音并收藏。
- TypeScript、相关 Vitest、后端 Ruff 与 Talk 测试、UI 检查、生产构建和治理 L1 审计通过。

## 3. 资产边界

Image2 原图、提示词和运行时 WebP 分开保存。操作图集固定为 4×4 格位，词本封面图集固定为 5×4 格位；组件映射与提示词同时维护，避免依赖模型生成的文字或自动识别图格顺序。

## 6. 讲义滚动与文档切换稳定性

- 《英语语法的历程与核心概念》的 7 张图表原先使用 220px 加载占位，实际高度约 157～585px；异步渲染还会将临时节点加入 body，造成文档及页面高度变化。
- 图表使用固定预览区域，加载、成功、失败保持同高；SVG 等比例完整显示，复杂图可点击放大。临时渲染容器脱离布局并在完成或失败后移除，已离开的文档不继续启动排队渲染。
- 文档切换在新正文提交后定位，重复点击当前文档保留阅读位置，仅更新时间变化不重建正文。概念定位绑定目标路径，不使用延迟定时器；搜索在正文提交后索引节点，清空查询时移除高亮。大纲与搜索只滚动正文栏，目录、正文和大纲阻止滚动链穿透。
- 固定窗口浏览器实测中，7 张图从部分加载到全部完成，正文高度始终为 23218px；页面无额外纵向溢出。重复点击当前文档前后 scrollTop 均为 18354.5，大纲和搜索操作后祖先滚动位置均为 0。快速切换三篇文档后最终正文正确，回到文首，无遗留渲染节点。
- 1024、1440、1920px 窗口宽度下无横向溢出，工具栏位置一致；图表放大及 Escape 关闭通过。网络桩注入非法 Mermaid 语法后，失败区域仍为 360px、无 body 溢出或临时节点；未修改真实讲义文件。
- `reader-scroll.test.ts` 覆盖标题对齐、搜索居中、超长块和文首边界。Web Vitest `1469 passed`，TypeScript、UI 检查和生产构建通过。本次仅修改讲义前端，不涉及数据库迁移、服务端或桌面打包。

## 7. 口语伙伴形象与语音网络

- 初版曾采用写实肖像与 MPFB 人物；两者退出当前应用资源，替代方案见第 8 节。显示模式切换不重建语音连接，隐藏页面停止动画，卸载释放模型与音频分析资源。
- 设置提供网络与代理入口：HTTP 地址、总开关、YouTube 下载、火山语音两个独立范围。火山语音包含实时对话、录音识别和 TTS，默认直连；启用代理是显式选择。配置存入 UserPref.network，不需要数据库迁移。
- 视频下载及 yt-dlp 元数据读取以网络设置为唯一代理来源，旧视频源凭据中的 proxy 不再生效；总开关关闭时显式禁用环境代理。其他模型供应商与系统 TUN/VPN 不在此开关范围内，界面说明该边界。
- `GET/PUT /config/network` 读取、校验和保存配置；`POST /config/network/probe` 只访问固定火山域名，不发送模型密钥、音频或对话。成功仅代表 HTTPS 网络可达，不代表语音鉴权或完整会话通过。新连接读取新配置，进行中的连接保持原路由。
- 本机日志存在火山 WebSocket 建连超时；一次无凭据网络对照中，直连 8 秒超时，HTTP 代理 127.0.0.1:7890 路径约 0.56 秒完成 TLS 并收到 HTTP 响应。该观测不能推导所有国内服务都需要代理，也不代表声音验收完成。
- 本机保存视频与火山语音代理开关后，真实火山 StartConnection / StartSession 连续三次成功，耗时 3141、2642、2374ms。固定测试问候返回 7 个音频块、210488 字节及 TTS 结束事件；未采集麦克风，也未以此作为实际扬声器或长时通话验收。
- 浏览器验证代理设置保存与刷新、用途开关、网络探针、人物选择和 3D/肖像切换；1024×640 与 1440×900 布局无横向溢出，人物等比例裁切。写实素材为二维形象，不声称完成真人驱动或照片转 3D。
- 后端全量 pytest 2173 条通过，其后补充 WebSocket 显式代理与网关错误回归，最终网络、语音和视频定向 85 条通过，Ruff 全量通过；Web 全量 Vitest 1484 条、TypeScript、UI 检查和生产构建通过。构建保留既有大 chunk、Harper 外置模块和混合导入提示。治理 L1 通过；不涉及数据库迁移或安装包签名。

## 8. 数字人运行时选型与替换

采用本地 VRM 人物与 three-vrm 运行时，复用 NEXUS 现有语音连接、播放器、字幕与学习辅助。不复制另一个完整聊天应用，不以生成肖像替代数字人，也不增加后台 GPU 服务。这是当前 Mac 本地产品的取舍，不代表所有数字人场景的统一最优方案。

## 10. 会话空间与回答历史

- 透明 VRM 与二次元阅读室共用背景，人物下沿柔化至字幕区域，移除人物与背景之间的硬分隔。插画以本地 WebP 加载，约 96 KiB；模型、语音连接和状态机保持独立。
- 右栏原句、推荐回答、场景关键句与提示统一使用全局 `WordModal`，保留词典、语境分析、发音、递归查词和收藏；不再插入右栏词卡或主动滚动右栏。
- 推荐回答每批三条，可换批、前后翻页。缓存按会话和原句隔离，离开原句后保留一小时，刷新应用清空；每句最多二十批。新请求携带批次与历史回答，失败保留已有批次，重试沿用未完成批次。翻页不请求模型，不自动发送建议。
- 增加重听、0.8 倍慢速听、停止朗读、复制句子、隐藏中文回想和四句卡壳应急表达；文字模式仍可填入输入框，需另行发送。
- 词本卡片宽度上限 184px，封面保持 6:5；缩小信息区间距，不再因单行卡片少而扩张铺满。加载占位遵循同一网格。
- 全产品二次元素材要求纳入 active 前端规范；用户学习原素材、截图与第三方标识不强制转绘。

## 11. 全局网络与服务目录

- 应用代理覆盖 HTTP、语音 WebSocket、Edge TTS、下载、免费翻译、受管 CLI 和 Electron 外部资源及更新请求；关闭时显式禁用环境代理，回环地址直连。HTTP 重定向逐跳判断目标。不会修改系统代理、TUN/VPN 或系统浏览器。

## 12. 流式朗读与发音评测

- Azure、Edge、阿里百炼与 Cartesia 采用流式音频输出，播放与本地缓存写入并行；失败或取消不提交残缺缓存，回退音色使用自己的缓存键。缓存按模型、音色、语速与协议参数隔离。
- 试听分别记录上游连接就绪、首音频块、浏览器首次播放与合成完成。无法观测的指标显示未提供，不以零值或完整合成耗时代替。浏览器播放事件不代表人工听感验收。
- 阅读只预取下一句，失败不阻塞当前句；常用单词复用本地音频缓存。对话按句缓冲并顺序播放，取消后旧轮次不再出声。
- 阿里百炼和 Cartesia 可配置、浏览音色及绑定朗读用途；MiniMax 只提供对照试听，不进入默认用途选择。新凭据不改变已有绑定。
- Azure 发音评测默认关闭，显式开启后按次提交短录音与参考句，展示整体及逐词结果。它不是实时对话模型，不自动采集或上传整场通话。
- 音色选择统一复用 VoicePicker，覆盖默认用途、供应商目录、阅读播放器、阅读偏好和场景本角色；按供应商、语言与声线筛选，保留分页、试听、延迟测试和当前选择。实时对话仅列可用的实时音色，MiniMax 仅能试听。
- 语速使用明确的弹出式选项，不再点击轮换。测试默认只显示首播延迟；分段数据收纳为诊断详情，不撑大用途绑定行。设置内选择音色时打开独立居中的模态窗口，保留后层设置的滚动位置；关闭或按 Esc 只退出最上层，焦点返回入口。

## 13. 自动辅助与持久对话记录

本节取代第 10 节中按原文缓存、仅在前端保留推荐批次的规则。数字人、二次元背景和实时语音厂商保持不变。

- 实时对话默认开启自动辅助。完整回复持久化确认后生成翻译、意图和三条推荐，开场白同样处理；增量字幕、未完整回复不触发自动生成。解释与推荐同时展开，可分别折叠，开关与折叠状态存入原有偏好。
- 每个会话的前端生成队列只运行一个请求；手动请求优先于未开始的自动请求。关闭开关取消排队中的自动任务，不取消已发送任务；重新开启只补当前完整回复。错误有明确重试入口，不循环付费重试。
- 右栏按消息 ID 关联。查词、回听、跟读或浏览旧批次时固定当前内容，新回复提示跳转，不覆盖正在看的批次。每轮最多二十批，每批三条；翻页、读取记录不调用模型。推荐不自动朗读、不自动发送。
- 顶部提供对话记录、暂停收音／继续对话、朗读设置、时长和结束会话。中央只保留最近两条字幕，人物区域与右栏分别约束高度；小于 900px 时辅助栏通过按钮展开。
- 记录查看器以五十条分页，按时间展示角色、原文、时间和不完整状态，支持原文／翻译／推荐搜索、角色和收藏筛选。加载更早记录保持阅读位置，新记录不强制滚动。历史回顾复用查看器。
- 原句支持逐句朗读、慢速朗读、复制与收藏；推荐收藏保留所属会话、消息和批次。解释及推荐中英文本支持朗读，英文点词复用全局词卡。无原音频时标注 TTS 重读，不使用“原声回放”。Markdown 与 JSON 导出包含原文及全部辅助批次。
- 仅允许删除已结束会话，确认后删除消息、关联批次、收藏和本轮专属分析缓存；仍有辅助任务运行时不能删除。会话先结束保存，再单独生成总结；总结失败仍能回看记录并重新生成总结。

### 数据与协议

- SQLite 迁移 `e9f0a1b2c3d4`，父版本 `d8e9f0a1b2c3`。`talk_turn` 增加稳定 `message_id`、`complete`、整条收藏与逐句收藏字段；旧消息保留 ID、原文和顺序，默认视为完整，不补算辅助。
- `talk_coach_batch` 以消息和批次建立唯一约束，保存生成状态、分析缓存引用、收藏回答索引及时间。内容复用 `analysis_result`，指纹包括用户、会话、消息、目标及之前最多十二条消息、场景、难度、历史推荐和版本。
- WebSocket 字幕与完成事件携带 `message_id`，写库后发 `turn_saved`，失败发 `save_error`。独立有序写入器不阻塞音频转发，重复完成事件幂等；暂时失败保留预分配顺序，结束时补存一次。音频帧格式不变。
- 新接口位于 `/talk/sessions/{id}` 下：`records`、`turns/{turn}/coach`、`turns/{turn}/saved` 及会话 DELETE。原有详情和手动辅助接口保持兼容，文字／录音对话不默认自动生成。
- 桌面服务启动时将未完成辅助标记中断，不自动重试；遗留未结束实时会话按最后一条消息时间关闭，没有消息则使用开始时间，避免把停机时长计入学习时间。

### 音频与弹窗边界

打开记录、词卡或开始回听时停止实时麦克风上行并清空 PCM 播放队列，暂停期间音频丢弃但文本继续保存；停止朗读、关闭窗口均不恢复收音。点击继续对话先停止回听，再恢复上行。跟读录音在打开记录、查词或会话结束时停止。

暂停只针对本地收音与播放，不承诺停止远端处理或计费。保留三十分钟会话上限及三分钟无上行超时；断开不关闭记录窗口，也不创建替代会话。

记录窗口最大 1200px、90dvh，工具栏固定、内容独立滚动。记录、全局词卡和音色窗口采用 Radix 焦点栈与全屏容器，Esc 仅关闭上层，关闭后回到原入口，不改变记录滚动位置。朗读音色和语速仅影响点读／重读，不改实时语音绑定。
