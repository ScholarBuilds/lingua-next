## 1. 变更背景

### 1.1 现状事实核对

| 事实 | 出处 |
| --- | --- |
| 三个 SPA 入口：`web/index.html`（后台）、`web/learning.html`（learning-core，`base=/learning-core/`）、`learner-web/`（前台：落地页、登录注册、引导、账号） | `web/vite.config.ts` 双 input；`learner-web/Dockerfile` 把 web 再 build 一遍塞进 `/learning-core` |
| 前台学习区整页跳转到 learning-core，后者用 `window.fetch` 补丁注入 CSRF 并把 `/api/config/prefs` 改写到 `/api/v1/me/preferences` | `web/src/learning-main.tsx` |

| 服务端 RBAC 三层 + 会话 + CSRF + 邀请码 + 审计：`user_account / role / permission / user_role / role_permission / auth_session / verification_token / invite_code / audit_event` | `domain/identity.py`、`app/auth.py` |

## 2. 裁决

### D1 一个入口，一个壳

全产品只有 `web/` 一个 SPA、一个 nginx、一个镜像。没有落地页、注册、引导、账号页；没有「发布」概念——导入即可学。

### D2 无登录；`user_id` 保留为本机 owner 常量

- 删除登录、会话、CSRF、RBAC、邀请码、审计与内容发布门禁，`app/main.py` 所有 `dependencies=` 去掉。
- 学习状态表的 `user_id` 列**保留**，值统一为常量 owner（服务端注入 `LocalOwner`，路由里 `auth.user.id` 改读 `owner.id`，查询不动）。这是 DEC-NEXT-003 说的「扩展点」：将来真要多用户，是在前面加一层鉴权，不是重新加列。
- 网络暴露：API 已绑 `127.0.0.1`（`tools/launch_nexus.py`），前端 dev/nginx 对局域网可达（麦克风走 `LAN_HTTPS`）。局域网可达保留为显式开关；开的时候可选一个共享口令（一个环境变量，浏览器首次输入后存 cookie），**不建账号**。同类本地工具的做法：Open WebUI `WEBUI_AUTH=false`、Stirling-PDF `SECURITY_ENABLELOGIN` 默认关、ComfyUI 默认只监听本机需 `--listen`、AUTOMATIC1111 `--gradio-auth` 可选口令（思路参考，P4 登记进开源复用清单）。

### D3 信息架构：按活动分组，不按角色

| 现名 | 新名 | 理由 |
| --- | --- | --- |
| 内容库 | 阅读 | 动作词，与其它入口同构；「库」是仓管口径 |
| 词汇资产 | 词汇 | 「资产」是运营口径 |
| 视频资产 | 视频 | 同上 |
| AI 对话 | 对话 | 全产品处处是 AI，前缀无信息量 |
| 工坊 | 工坊 | 不变 |
| 任务 · 管线 | 任务 | 一个入口，见 D4 |
| 前台内容 · 用户 · 退出 | 删 | 无前台、无用户 |
| 学习素材 · 创作与运行 · 运营管理 | 学习 · 创作 | 底部固定区放任务、设置、主题、收起 |
| （无） | 今天 | 首页，见 D5 |
| （无） | ⌘K | 命令面板，见 D6 |

路由：`/` → 今天；`/read`（原 `/content`）、`/read/:id`；`/video`、`/video/:id`；`/vocab`；`/grammar`；`/talk`、`/talk/session`；`/studio/*`；`/tasks`；`/pipeline/*` 深链保留、导航高亮「任务」；`/settings/:section?`。
删除：`/login` `/register` `/forbidden` `/users` `/catalog` `/learning-core/*` `/app/*`。

沉浸式路由（阅读器、视频学习、对话会话）与页面级 `Topbar` 契约（返回 · 面包屑 · 标题 · 状态 · 动作）不变。

### D4 任务与管线合成一个入口

M61 已把 StudioTask / FlowRun / PipelineRun 折成一份列表、一条事件流；再保留「任务」「管线」两个一级入口加右下角 `RunningDock`，同一件事在三处各说一遍。合并后：一级只留「任务」（带在跑/失败徽标），管线中心成为任务页里按域的视图，节点级重跑与产物层的页面原样保留为下钻；`RunningDock` 收进侧栏「任务」项的展开面板。

### D5 首页「今天」

打开即可接着干：**接着来**（上次读到哪、看到哪、练到哪，各一张卡）· **在跑**（同一条事件流）· **最近加入**（导入卡内联）· 右列到期复习数与本周时长。数据源已有：`reading_progress`、`video_study_progress`、`study_time_log`、`vocab_entry.due_at`，与被删的 `/v1/me/dashboard` 聚合逻辑同源，搬到 `/config` 或新建 `/home` 端点即可。

### D6 命令面板 ⌘K

`cmdk` 已是依赖，`components/ui/command.tsx` 已在（当前只用在词库场景栏、凭据选择、画布 @ 提及）。全局层：搜书 / 视频 / 单词、跳页面、执行动作（导入、开始复习、新建画布、切主题）。侧栏顶部一个搜索形态的入口，键盘 ⌘K / Ctrl+K。

### D7 删除清单

**前端**：`learner-web/`（含 Dockerfile、nginx.conf）；`web/learning.html`、`web/src/learning-main.tsx`、`web/src/learning/*`、`web/src/styles/learning-core.css`；`web/src/features/admin/*`；`web/src/lib/api-admin.ts`；`vite.config.ts` 回单入口、去 `LEARNING_CORE_BASE`；各组件的 `readOnly` / `learnerMode` 形参与分支。

**服务端**：`app/auth.py`、`app/learning_access.py`、`domain/identity.py`、`routers/{auth,me,admin_users,admin_catalog,learner_catalog}.py`；`config.py` 的 `session_*` / `csrf_*` / `registration_invite_only` / `bootstrap_admin_email`；CORS 的 `X-CSRF-Token`；依赖 `argon2-cffi`。

**数据表**：`role` `permission` `user_role` `role_permission` `auth_session` `verification_token` `invite_code` `audit_event` `content_publication` `user_preference`（并回 `user_pref`）；`user_account` 整表删（owner 是常量不是行）；`user_resource_progress` `user_word_state` 是前台目录的投影，P1 核对无独有数据后删。

**部署**：`docker-compose.yml` 删 `learner-web` 服务，`admin-web` 改名 `web`；env 删 `LINGUA_BOOTSTRAP_ADMIN_EMAIL` `LINGUA_REGISTRATION_INVITE_ONLY` `LINGUA_SESSION_COOKIE_SECURE`。

**测试**：`server/tests/test_identity_api.py`、`test_learner_catalog.py`、`learner-web/src/**/*.test.*` 删；依赖登录态的夹具随之清理。

### D8 数据迁移

一条 Alembic 迁移：各学习状态表的 `user_id` 改写为 owner 常量并去掉指向 `user_account` 的外键；随后删 D7 列出的表。执行前先 `pg_dump`，并把非 owner 账号（若有）的学习数据导出 JSON 存档进 `归档/`。

## 3. 影响评估

| 维度 | 评估 |
| --- | --- |
| 功能 | 学习功能零损失：前台能做的后台全能做。损失的是「给别人用」这条路，见 §6 Q2 |
| 数据 | 学习记录保留并归到 owner；账号、会话、发布状态删除 |
| 安全 | 从「账号 + 会话」退到「本机默认 + 局域网可选口令」。与 Docker 里数据库只绑 `127.0.0.1` 是同一姿态 |
| 部署 | 少一个镜像、一个 nginx、一个端口（8081）；启动脚本少一段 |
| 文档 | 信息架构文档 §1/§2 重写；设计系统文档 §1.1 的壳色（仍写 #22252A）与 `design/mockups/tokens.css` 镜像（仍是墨石深底 + 64px 图标栏）本就落后于 `web/src/styles/tokens.css`，本轮一并同步 |
