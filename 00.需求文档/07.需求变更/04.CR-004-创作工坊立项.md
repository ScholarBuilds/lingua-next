# CR-004 创作工坊立项

- **提出日期**：2026-08-20
- **决策人**：scholar
- **涉及需求**：新增模块 17（FR-460 ~ FR-481、BR-140 ~ BR-150、AC-140 ~ AC-155）
- **触发**：用户原话「他的那个项目里面的所有功能都给我搬到我的项目里面来……搞一个
  工具中心……把当前 Infinite-Canvas 里面的所有功能都搬过来……每个工具的能力都不能
  比 Infinite-Canvas 原来的能力差，只能更好」
- **状态**：需求定稿，M1 实施中

## 1. 决策

| 决策 | 结论 |
| --- | --- |
| 命名 | 创作工坊（导航「工坊」，`/studio`） |
| 移植方式 | **功能复刻**，不复制代码——蓝本许可证（禁商用 + 二开传染开源 + 署名）与技术栈（19k 行单文件 Python + 944K vanilla JS）双重不接 |
| API 设置归属 | 配置中心（模块 10/11），不进工坊；8 协议适配层由 LiteLLM 承担 |
| 资产底座 | 模块 16 `image_asset` 唯一底座，工坊产图全部入库带血缘 |
| 生图控制台 | 入驻工坊为一个工具，路由 `/image` 不迁移 |
| 裁剪 | 自更新、CLI 桥、数字人、MiniMax 时间线、Chrome/PS 插件、ComfyUI/RunningHub 直连不做（模块 17 §7 逐条理由） |

## 2. 调研依据

- 同中转同模型实锤：两边上游都是 `ai.whyuz.com.cn` / `gpt-image-2`，像素上限同为
  ≈1.57MP；差距在参考图锚定循环、原话直达、auto 尺寸、画布迭代 UX（模块 16 六轮记录）。
- 全量精读：6 并行读者covering后端 19,038 行与前端全部页面，107 项功能、231 端点、
  145 条坑，底稿存会话工作流 `infinite-canvas-full-read`（2026-08-20）。
