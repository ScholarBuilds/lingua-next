# CR-001 生图控制台形态与能力范围

- **提出日期**：2026-08-20
- **决策人**：scholar
- **涉及需求**：FR-421（反转）、FR-427 ~ FR-441（新增）
- **触发**：用户给出竞品（豆绘AI）控制台的六张截图，要求对齐业内形态与功能密度
- **状态**：已实现（2026-08-20），实施记录见[需求说明 §14.6](../02.功能需求/16.生图与视觉资产/需求说明.md)

## 1. 反转项

| 编号 | 原口径 | 新口径 | 理由 |
| --- | --- | --- | --- |
| FR-421 → FR-428 | 生图页整屏独占，隐藏左侧主导航 | **保留左侧主导航**，改为常规页面 + 页内三栏 | 原论证「创作需要大画布」只在一次性出图下成立。三轮后生图是常驻工作区，出图→回词库看效果→回来改图的往返频率压过了画布面积。画布损失改由「点击进入全屏审图」补偿 |

> [!warning] 旧口径不再有效，实现时以 FR-428 为准
>
> FR-421 正文保留在需求说明里作为决策历史，但 `/image` **要从 `App.tsx` 的 `hidesRail()` 摘掉**
> （注意不是 `isImmersive()`，那是阅读器与视频页的「只隐顶栏、留 rail」，两个函数分开）。
> 同时存在两个口径正是本目录要防的事，这里显式作废旧的那个。

## 2. 新增项

| 类别 | 内容 | 需求编号 |
| --- | --- | --- |
| 架构 | 应用注册表：约 30 个功能格子背后只有 4 条通路（generate / edit / vision / local），加应用 = 加数据 | FR-427 |
| 交互 | 应用选择器、提示词工作区、蒙版画布、结果查看器、编辑链血缘 | FR-429 ~ FR-431、FR-434 ~ FR-435 |
| 能力 | 尺寸改「比例 × 分辨率档」、流式部分图、描述词反推、批量策划台、资产库升级、成本前置 | FR-432 ~ FR-433、FR-436 ~ FR-439 |
| 能力包 | 基础修图（Filerobot）、电商与人像应用包 | FR-440 ~ FR-441 |

配套业务规则 BR-114 ~ BR-121，验收 AC-109 ~ AC-117，分期五期至九期。

## 3. 否决项与理由

用户选了「再加电商与人像类」，但竞品另有几块**明确不跟**：

| 竞品能力 | 否决理由 |
| --- | --- |
| 4K 放大 / 超分 | 无本地 GPU；上游重绘放大会改画面。Pillow 插值不增细节，叫「放大」是骗人 |
| 去水印 | 无对应模型，且去他人水印有版权风险。加水印做 |
| 无限画布 / 模型训练 / 3D / 视频 | 本平台无落点，前两者还需要已被 ADR-009 排除的本地推理栈 |
| 图像广场（公开作品流） | 自用产品没有这个内容源，做出来是空页 |
| 提示词自动优化开关 | 静默改写输入会让「改了词但没变化」无法归因，只做显式按钮 |

## 4. 影响评估

| 维度 | 影响 |
| --- | --- |
| 数据库 | `ImageAsset` 新增 `parent_id`、`op`、`source` 三列（编辑链血缘 + 本地产物标记），需一次迁移 |
| 后端 | 新增应用注册表；`edits` 通路复用，编辑类应用**零新接口**；流式需探测中转是否透传 |
| 前端依赖 | 新增 `filerobot-image-editor`（MIT）及其对等依赖 `react-konva` / `styled-components`，约 +300KB gzip |
| 路由 | `/image` 从 `App.tsx:hidesRail()` 摘掉，改 `/image/:appKey` |
| 成本 | 默认档位不变（1K / medium）；2K 与 high 需显式选择并在按钮上标出档位（BR-120） |
| 既有实现 | FR-421 的整屏布局需回退；二轮的三栏结构保留复用 |

## 5. 待验证前提

以下两条在实现前必须先跑通，不成立则对应需求降级：

| 前提 | 不成立时的降级 |
| --- | --- |
| 中转网关透传 Images 流式（`stream` + `partial_images`） | FR-433 退回二轮形态（状态 + 已跑秒数），**不得伪造中间帧**（AC-113） |
| 分辨率档位标定：每档实发一张最低质量图，记录实际返回尺寸 | 档位表以实测值为准而非官方文档（AC-112）。已有先例：`1536x608` 实测返回 `1994x789` |
