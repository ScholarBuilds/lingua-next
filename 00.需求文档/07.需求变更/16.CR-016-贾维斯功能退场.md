# CR-016 贾维斯功能退场

- 提出：scholar，2026-09-03
- 状态：已完成
- 基线：`aec2177`
- 替代：CR-008、CR-009、CR-010、CR-011、CR-012、CR-013、CR-015 中的贾维斯产品范围

## 1. 决策

1. 从工作台导航、命令面板、首页、设置和路由中移除贾维斯，不保留隐藏入口或兼容跳转。
2. 桌面壳不再创建刘海、悬浮层和审批窗，不注册贾维斯快捷键、常听、原生唤醒、紧急停止或 CuaDriver 权限流程。
3. 桌面安装包不再携带 Codex、唤醒帮助进程、贾维斯策略文件和专属执行依赖。
4. 服务端不再挂载贾维斯会话、语音和电脑控制路由，也不在启动时恢复或停止贾维斯任务。
5. 普通口语练习、TTS、ASR、邮件、任务、工坊、扩展和通用 MCP 能力保留；只有被贾维斯独占的代码和配置退场。
6. 历史数据库迁移文件保留，现有贾维斯记录不自动删除。退场不执行用户数据销毁；后续如需彻底清除，另立带备份与确认的数据迁移。
7. 既有 CR 与 ADR 作为决策历史保留并标记已被本变更替代，不删除历史文档。

## 2. 验收

- 工作台不存在“贾维斯”导航、设置、HUD、快捷命令和可访问路由。
- 启动 NEXUS 不产生贾维斯、Codex、CuaDriver 或唤醒监听子进程与辅助窗口。
- 桌面运行时中不存在 Codex 和 wake-listener 目录。
- `/jarvis/*` 与专属语音 WebSocket 不再注册。
- 普通对话、学习、邮件、任务、工坊和扩展的相关测试与构建保持通过。
- 后端、Web、桌面测试及治理 L1 审计通过。

## 3. 可恢复性

退场通过提交历史和保留的数据库表可恢复；不保留运行时兼容代码、隐藏开关或无法验证的半退场状态。

## 4. 实施结果

- Web 已删除导航、路由、命令面板、HUD、设置、语音客户端、状态 Store 和所有资产。
- Electron 只保留主窗口、本地 sidecar、托盘、外链、下载和更新；preload 只暴露 `openExternal`。
- API 已删除 `/jarvis/*`、专属语音 WebSocket、审批门、执行会话、主动播报、唤醒与电脑操控运行时。
- 一键启动不再检查 `interpreter`、`agent-browser` 或 `cua-driver`；原有用户级 CuaDriver daemon 已停止，但未卸载外部应用或清除 TCC 记录。
- 历史数据库模型与迁移保留；本次未删除现有用户记录、执行证据或日志。
