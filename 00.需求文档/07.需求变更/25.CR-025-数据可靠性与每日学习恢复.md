# CR-025 数据可靠性与每日学习恢复

- 日期：2026-09-06
- Owner：scholar
- 状态：四批实现完成；发布环境验收项保留

## 范围与交付顺序

1. 画布离页保存、评分与场景提交幂等、学习阶段统一、题型转换、设置同步、素材批删授权。
2. 队列终态重跑、导入派发恢复、任务摘要与历史、桌面迁移备份、进程恢复及导航更新边界。
3. 自动汇总且可置顶、当日暂放的今日计划，接回各模块真实断点。
4. 数据库分页、路由隔离、公共传输和工坊职责拆分。

## 契约

保留 React、FastAPI、SQLite、Electron 与服务器开发档。人工学习标记优先，专项练习不写正式调度。重复提交返回首次回执，过期版本返回冲突；重练有独立轮次。保存队列独立于页面生命周期，失败保留重试数据。强删授权只针对展示并确认的素材集合。桌面迁移不覆盖用户数据。首页不自动调用模型、播放或开启麦克风。

## 验收

每批独立验证和提交。故障用例覆盖保存中切页、响应丢失和并发评分、设置初始化与写入竞争、入队失败与重跑、第六项引用、旧库迁移失败、分页上限、跨午夜及失效断点。自动化测试与真实页面、打包桌面验收分别记录，不互相替代。

## 证据

实施前基线：提交 555eb13；工作区干净。各批结果随实际验证补充。

### 第一批

- 画布保存捕获不可变文档，按画布串行排队；离页后的冲突合并使用该快照与墓碑，本机草稿保留失败结果。设置按字段保留本地修改，写入串行，失败提示提供重试，缓存不可用不阻断内存状态。
- `learning_receipt` 在评分事务内占位，保存请求指纹与首次响应。正式训练、场景提交和带提交 ID 的旧复习请求接入回执；场景版本采用比较更新，重练使用独立轮次。旧无 ID 复习调用保留兼容保护，尚未到期时不重复评分。
- 场景校验存在性、词汇归属和计数范围，重复词归一。人工标记优先于调度派生；报告实时派生状态，`reconcile_status` 默认只读对账，显式 apply 才修正缓存。错题转拼写重建题面；旧听写不写正式调度。
- 批删预检全量 ID，强删按 `force_ids` 授权；服务端重新检查引用，旧整批 force 布尔值不再授权多项强删。共享存储对象仍按持有者保留。
- 验证：前端偏好、画布与词汇目标集 70 项通过（另补离页 409 用例）；后端学习、素材删除目标集 45 项通过，文件 SQLite 并发及状态对账、素材存储、词表集 22 项通过。类型检查、UI 守卫与触及 Python Ruff 通过。
- 真实页面和打包桌面尚未验收；数据库迁移与恢复接入属于第二批，不能仅凭新增迁移文件视为升级完成。

### 第二批

- 本地队列按执行 ID 保留历史，仅对活跃业务键去重；Redis 使用活跃执行指针。文章、书籍入库同步记录派发意图，启动与定时恢复补派，回执中断使用同一执行 ID。
- 任务中心使用跨领域身份、服务端游标分页和独立摘要；侧栏与运行浮层读取相同去重口径，历史支持带领域的 ID 定位。
- 桌面启动在合并内容前执行 SQLite 一致性备份和 Alembic 迁移，失败恢复原库。内容冲突保留部分完成标识；启动失败提供恢复入口，重启预算只在持续稳定后重置，未就绪进程超时终止。导航、外链与 IPC 限定来源；更新器直接使用验签后的元数据。Docker 默认绑定本机，CI 加入桌面类型、测试与升级检查。
- 验证：队列、派发、任务历史、桌面迁移与启动目标集 25 项通过；前端任务行为 53 项通过，类型检查通过。桌面目标测试与类型检查通过。真实桌面故障窗口、签名更新源和 Redis 服务尚未进行外部集成验收。

### 第三批

- `/home` 补充正式训练和语法续练摘要、新词额度及完成次数，时长与额度按学习时区计算。本机速记与听读只读原断点；首页的置顶、当日暂放和恢复写入既有偏好存储，不修改答题记录。
- 今日安排按到期、未完成、新词余额、最近内容排序，置顶优先；跨日解除暂放，失效内容在继续前检查并提供返回。听读恢复只定位，不自动播放；首页不发起模型或麦克风请求。
- 真实页面检查发现深色文字叠在浅色纸纹上，深色模式移除内容壳纸纹，浅色品牌样式保留。SQLite 时间在响应中带 UTC，避免浏览器重复套时区。
- 验证：后端首页 4 项、前端安排/偏好/听读 21 项通过；类型及 UI 守卫通过。内置浏览器验证 1440 × 900 和窄窗口、深浅主题、置顶、暂放、刷新后恢复、键盘关闭设置，以及原训练第 3 题续接与返回。真实跨午夜由时区与跨日用例覆盖，未等待自然午夜。

### 第四批

- 词表过滤、阶段、计数、排序和分页下推数据库，生词本、自建本和考试词表共用阶段规则。封面汇总同步使用相同规则，清空进度但保留收藏时计为未学；1,603 和 10,000 词用例校验总数、稳定排序和仅装配当前页。
- 学习、工坊及重型页面使用路由懒加载，设置和实时对话宿主延迟载入。路由错误保留导航、重新加载和返回入口；针对当前 React Router 的懒加载失败补齐叶级 fallback，故障注入复现和回归通过。
- 公共 HTTP 传输统一结构化错误、网络错误和取消语义，各领域保留自己的 API 与错误契约；写请求不自动重试，流式和下载保持专门通道。
- 工坊抽出保存队列、剪贴板编辑、运行状态和远端文档合并。停止运行唤醒等待者并清除计时器，现有画布合并、墓碑和快捷键相关测试继续通过。
- 速记待提交的原始请求在发送前持久化，刷新后复用同一回执身份与版本；场景首次并发创建采用唯一约束下的冲突忽略与版本比较。置顶的历史内容不因最近项目变化而消失，内容删除后保留说明和模块返回入口。
- 任务历史保持服务端游标顺序，窄窗口筛选栏可换行。更新元数据验签拆为可测试边界，覆盖签名、内容篡改、来源和版本不匹配。

- 后端最终全量 2,391 项通过，触及范围 Ruff 通过；旧库迁移与回退由后端测试覆盖。桌面类型检查、构建和 17 项测试通过，覆盖进程策略、导航及签名元数据边界。
- 临时隔离 Redis 实例配合真实 ARQ worker 验证活跃任务去重、终态重新执行与独立结果回执；进程和临时数据在验证后清理。
- 内置浏览器验证今日安排的桌面与窄窗口、深浅主题、刷新恢复和练习深链返回；任务中心从 50 项加载至 100 项、失败筛选与历史领域 ID 定位。阻断页面模块下载时，导航与重试入口仍可用，解除阻断后重新加载可恢复。运行库中考词表封面与筛选均为未学 977 词，总量 1,603 词，窄窗口可正常切换筛选。

### 词卡、模型选择与工坊入口回归

- 词卡挂载时查询服务端已有语境释义，未命中不发起模型生成；缓存按词、语境与指定模型隔离。普通词卡与听读词卡复用同一读取路径。
- 听读词卡由原播放器驱动，沿用内容、重复、循环与切词设置；开关词卡不暂停播放，自动推进替换当前卡，卡内提供暂停和前后切词，空格与左右键使用同一播放器。手动查其他词时退出跟随。
- 模型选择器与设置、词卡共用 Radix 嵌套焦点管理，保留浮层栈对后台快捷键的阻断；工坊侧栏固定进入应用首页，创作对话与历史记录保留。
- 内置浏览器验证已有 `have` 释义直接显示、模型搜索和关闭后保留设置；听读从 `to` 自动切到 `you`，缓存可见，暂停与恢复正常，关闭词卡后仍播放，工坊入口显示应用首页。重复与循环的次数由原播放器回归用例验证。
- 键盘实测：模型选择器按 Escape 只关闭自身，设置仍在；暂停状态打开听读卡不会自行播放，空格切换播放与暂停，右键从 `you` 切到 `he` 并继续沿用播放器。
- 验证：前端最终全量 1,624 项通过；后端模型与缓存目标集 24 项通过，缓存未命中、换语境和指定模型隔离均不会生成新解释。类型检查、构建、UI 守卫与触及 Python Ruff 通过。
