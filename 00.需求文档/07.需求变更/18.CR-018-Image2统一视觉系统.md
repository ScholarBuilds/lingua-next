# CR-018 Image2 统一视觉系统

- 提出：scholar，2026-09-03
- 状态：已实现
- 影响：Web 全局样式、导航、页面水印、工具图标、Web 图标、桌面应用图标

## 1. 决策

1. 工作台使用同一套暖纸、墨蓝、钴蓝、清透青和暖黄视觉语言，不再按页面拼接不同来源的开源图标。
2. Image2 生成四类源资产：应用标识、16 个业务领域插画、36 个通用操作图形和纸张网格纹理。生成提示词随资产保存在 `garden-gpt-image-2/prompt/`。
3. `NexusVisual` 负责业务领域插画，`NexusIcon` 负责操作图形；导航、公共控件和工坊工具统一从这两个入口取图。
4. 业务页面仍由 React、HTML 和 CSS 排版。图表、波形、语法结构、画布连线等数据型图形继续实时绘制，不使用静态图片替代。
5. 图片图集只加载一次并由浏览器缓存，组件通过裁剪视口复用；运行时副本转成 WebP，避免为大量小图标发起独立请求或携带无效体积。
6. 浅色内容区使用低对比度纸张纹理，深色主题降低图形亮度；插画只承担识别和层级，不遮挡正文与交互。
7. 操作图形与业务领域插画采用年轻化二次元赛璐璐语言：深墨蓝轮廓、明快纯色块和有限高光。禁止写实桌面摆件、传统企业线框图标、人物脸、文字标签和背景卡片进入图集。

## 2. 覆盖范围

- 一级导航：今天、阅读、视频、词汇、语法、对话、工坊、邮件、账户、扩展、任务、设置。
- 创作域：生图、工作流、画布和资产库。
- 公共操作：导航、增删改查、播放、上传下载、文件、状态、权限和工作流。
- 品牌入口：浏览器 favicon、Apple Touch 图标、侧栏标识、Electron Dock 和打包图标。
- 全部路由：通过全局令牌、纸张纹理和按路由变化的领域视觉建立统一页面背景。

## 3. 验收

- Web 不再依赖 `lucide-react`，源码和锁文件不存在该依赖。
- 所有业务路由共享同一套颜色、字体、圆角、描边、背景纹理和领域视觉规则。
- 1024×768 与桌面宽屏下主页面没有横向溢出。
- 图标按钮继续保留可访问名称、键盘焦点和至少 32×32 的命中区。
- TypeScript、UI 检查、Vitest、生产构建与 Electron 探针通过。

## 4. 资产边界

生成图片是项目自有视觉资产，不登记为第三方代码依赖。原始生成结果保留在本机生成目录，仓库保存产品使用副本、应用标识源图和提示词；后续改版应从提示词重新生成整组资产，避免单页临时拼图导致风格漂移。

## 5. 实施证据

- 二次元图标改版后，两张透明图集保持固定 6×6 与 4×4 格位；现有组件映射和无障碍名称无需迁移。
- 运行时两张图集合计约 1.09 MiB，旧导航 PNG 和被否决的写实、企业线框图集不再被页面引用。
- 13 个一级路由在 1440×900 下完成真实页面巡检，全部加载对应领域图和操作图形；旧导航图片请求为 0。
- 今天、语法、工坊、数据设置在 1024×768 下复验，页面和主内容区均无横向溢出。
- Web 101 个测试文件、1460 条测试通过；TypeScript、UI 检查和生产构建通过。
- Electron 10 条单测和 13 项真实壳探针通过。
- 保险箱巡检暴露的历史 `volc_duplex` 类型崩溃已改为兼容展示；相关后端 Ruff 与 10 条测试通过，真实接口恢复 200。
- 2026-09-03 二次元图标改版在首页和工坊完成真实浏览器复验；操作图集、领域图集均从新 WebP 加载，1024×768 无横向溢出、控制台无错误。改版后 Web 101 个测试文件、1460 条测试，TypeScript、UI 检查和生产构建再次通过。
