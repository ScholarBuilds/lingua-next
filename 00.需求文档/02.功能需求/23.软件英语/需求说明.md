# 软件英语 Markdown 讲义库

状态：阅读器与迁移已实现；macOS 教程正在逐篇人工重写。主入口为 `/grammar?tab=software`；旧 `/software-english` 仅承担兼容重定向。

## 产品形态

软件英语是“英语讲义”的第五个集合。点击 Tab 始终回到软件库选择页；选择软件卡片后进入与语法、词汇、句型和场景一致的三栏 Markdown 阅读器。每个软件独立保存最近文档、阅读位置、已读状态、笔记、书签和目录展开状态。

首个软件库是本机 macOS 系统设置 27.0 Beta（26A5425a）。软件卡片展示版本、采集日期、教程篇数、截图数和阅读进度；卡片主体打开大纲，“继续学习”恢复该软件最近文档。

## 教程与图片

教程源位于本机 Obsidian `05.软件英语/01.macOS系统设置/`。新目录按用户要解决的功能命名，图片作为正文中的“界面实例”出现，不得以文件名、图号或“某某截图”占据讲义目录。每篇由人工按功能原理、真实路径、界面语言、操作案例、恢复方式、英语表达和自测组织；所有 456 张原始截图将逐篇人工归入对应主题。

Markdown 使用标准相对图片路径。NEXUS 通过 `/grammar/docs/assets/{software_id}/{relative_path}` 读取原图；接口仅允许桌面运行档和回环请求，只读取当前软件 `_assets/screenshots/` 下经内容签名确认的 PNG/JPEG，拒绝绝对路径、路径逃逸、点号目录、符号链接和其他文件类型。响应使用 `private, no-store` 与 `nosniff`。

图片可点击放大，Esc 只关闭最上层并恢复原焦点。图片失败时显示文件名和错误状态。原始截图、教程正文和旧来源映射保留在本机，不进入 Git、通用素材库或云端同步。

## 阅读与共享学习能力

软件教程复用讲义文档树、目录筛选、全库搜索、文内搜索、上一篇和下一篇、字号、行宽、大纲、笔记、本节练习空状态、批注、书签、朗读、复制和 AI 完善。软件讲义的 AI 提示词禁止改写真实界面英文，并要求保留图片引用、稳定锚点、表达表、来源和版本说明。

点词继续打开全产品统一词卡；词典、AI 语境释义、拆开记、TTS 缓存、收藏和学习状态不建立软件专用副本。软件出处统一为“软件 → 文档 → 锚点”。旧 collection/page/capture/entry 由本机 `legacy-source-map.json` 解析；无法映射时明确显示“原截图定位已归档”。

## 内容生产与版本

教程不使用批量文案脚本生成。每篇完成后才进入阅读器；旧脚本草稿统一保留在本机 `_归档-旧版/脚本草稿-2026-09-09/`，不参与扫描。软件升级时保留稳定文档名与锚点，旧版本移入本机归档，软件库只展示最新版。

教程以真实截图和辅助功能文本为界面事实，Apple 公开指南只补充功能解释。本机 27.0 Beta 与公开 Tahoe 26 指南存在差异时按“本机观察”处理。受限页面保留原因，不通过切换网络、权限、账户或订阅制造截图。
