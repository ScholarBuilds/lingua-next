# 场景学习

## 1. 模块目标

维护结构化的场景教材内容库（对话脚本、场景词组、文化提示），作为口语练习（07 模块）与表达学习的素材源。场景学习没有独立的练习界面——它是口语页的一个内容栏，避免旧版"两套场景数据互不相通"的教训。

## 2. 功能需求

### 2.1 场景内容库

- FR-01 场景对话结构：场景目标（如办理入住）、参与角色、前置背景、对话轮次（每句含译文/重点词组/发音）、可替换回答、文化与礼貌提示、内容来源标记（人工编写/AI 生成）。
- FR-02 场景词组：原文 + 自然译文、使用场景、正式程度与语气、可替换表达、常见错误、例句；排序按频率 + 场景相关性，不按模型输出顺序。
- FR-03 首批场景（10 个）：日常问候与自我介绍、餐厅点餐、问路交通、酒店入住、购物、工作会议、面试、机场值机、电话沟通、就医基础用语。
- FR-04 场景编辑器（M4）：用户可新建/修改场景，AI 辅助生成初稿后人工确认入库。

### 2.2 场景化学习方式

- FR-05 浏览学习：场景页阅读对话脚本，逐句点读（复用点词/点句/朗读全套能力）、角色分轨朗读（不同音色扮演不同角色）。
- FR-06 进入口语练习：任一场景一键发起 07 模块的实时对话，场景目标/角色设定/关键句注入会话 prompt。
- FR-07 素材联动："我读过的"栏列出用户最近查过的词与句，可作为下一轮练习素材（旧版 CHG-0009 设计继承）。
- FR-08 场景词组可收藏进词库，带场景语境。

## 3. 业务规则

- BR-01 人工审核内容与 AI 生成内容必须标识区分。
- BR-02 医疗、法律、金融场景仅提供语言学习内容并附免责声明，不提供专业建议。
- BR-03 场景数据模型与口语练习共用（同一份场景表），不建第二套。
- BR-04 场景推荐与当前学习内容有可解释关联（如书中出现餐厅对话推荐点餐场景），不做黑盒推荐。

## 4. 实现方案

| 部件 | 方案 |
| --- | --- |
| 内容格式 | YAML 场景文件（仓库内维护）→ 启动时同步入库；用户自建场景直接入库 |
| 初稿生成 | LLM 按场景 schema 生成 + 人工确认；schema 校验强制 |
| 角色朗读 | TTS 音色目录按角色绑定（06 模块） |
| 练习接入 | 场景 → 07 模块会话 prompt 模板的参数化注入 |

## 5. 验收要点

- AC-01 场景对话逐句可点读可收藏，与书库点读体验一致。
- AC-02 从场景发起实时对话，AI 遵循角色设定与场景目标；刚看过的关键句可被 AI 在练习中使用。
- AC-03 AI 生成的场景初稿未确认前不出现在正式场景列表。
