# 朗读与语音中心

## 1. 模块目标

单词、句子、整篇都能用用户喜欢的口音与嗓音朗读；音色跨供应商统一管理，语速按场景分别记忆，朗读队列全局单例，整篇朗读句级高亮跟随。

## 2. 功能需求

### 本机语音与词库预热

Mac 声音选择器列出本机 say 可用音色，使用已安装声音本地合成，转换后保存到统一 TTS 缓存。
需要 macOS 与现有 ffmpeg；其他平台不显示本机入口。声音目录在服务启动后首次读取并缓存，
安装新声音后需重启服务刷新。默认音色不自动修改，词级固定音色在各处词卡共同生效。
首次本地合成仍有延迟，缓存命中可避免重复合成，不能承诺零延迟。

词库 AI 补全提供可选的词与例句音频预热，音频最多 4 并发，文本保持既有并发。
预热按固定词音色或场景默认音色寻址；临时播放音色不写入后台任务。
已存在音频跳过，失败计入任务失败数，重跑可补缺。换音色或语速后是不同缓存。
语境释义按词、句子、模型寻址；拆词按原形寻址，不把不同语境的释义混用。

本机接口实测 security / Samantha 首次约 2.48 秒，缓存请求约 4 毫秒；
该数值是接口返回时间，不是端到端出声延迟。内置浏览器试听完成。
验证覆盖共享缓存寻址、预热跳过与失败、跨来源学习标记、中文讲义路径保存。
后端相关回归 66 项通过，音频追加回归 15 项通过；前端 14 个文件、132 项通过，
类型检查、UI 守卫和生产构建通过。浏览器检查讲义切换恢复、词卡学习状态、
Mac 试听和批量预加载选项，没有启动整本合成任务。

共享词卡提供学习中、困难词、已掌握标记，复用词库的学习阶段接口。
遮挡自测接收标记更新并保留卡片位置，切换筛选后再更新成员。
导航名称为英语讲义；分类切换恢复上次文档，已加载的目录和正文复用查询缓存，
保存文档后由查询失效刷新内容。

### 2.1 音色与供应商

- FR-01 三档 TTS 供应商：免费档 edge-tts（微软在线音色，非官方端点）、高质量档 OpenAI TTS / Azure TTS（按需配置）、本地档 Kokoro（可选容器，离线可用）与浏览器 Web Speech API（兜底）。
- FR-02 统一音色目录：跨供应商列出可用音色（名称、口音 en-US/en-GB/en-AU 等、性别、供应商、试听按钮固定示例文本）；音色目录数据库化，供应商探针刷新可用性。
- FR-03 场景音色绑定：查词发音、句子朗读、整篇朗读、背单词发音可分别绑定音色；未绑定时用全局默认。
- FR-03a 释义朗读（`tts-meaning`，2026-09-05）：听读单词时念中文释义走这一档；没绑时回落 edge 晓晓（与助理朗读同理，英文音色念中文一个字不出）。按词钉死的音色见词库 FR-495。
- FR-04 语速音量可调并实时试听；单词/句子/整篇分别记忆各自语速。
- FR-05 来源策略用户可选：供应商优先失败回退（默认）/ 仅本地档 / 仅指定供应商（不可用时明确报错不静默回退）。回退发生时标注本次实际使用的音源。

### 2.2 朗读行为

- FR-06 朗读队列全局单例：新播放请求停止旧队列；点词/点句/整篇/背单词共用，不允许多路重叠。
- FR-07 整篇朗读：句级顺序合成与播放、当前句高亮 + 自动滚动、句间停顿可配、上一句/下一句/暂停/继续/倍速；手动滚动暂停跟随。
- FR-08 页面不可见（`visibilitychange`）时按用户设置决定继续或暂停；恢复后从暂停处继续。
- FR-09 自动朗读开关：翻译/查词完成后自动朗读，超过字符阈值（默认 30）不自动读。

### 2.3 缓存

- FR-10 TTS 音频按 `(文本hash, 供应商, 音色, 语速)` 缓存本地卷；Azure、百炼与 Cartesia 进一步按账户、模型、地域与协议参数隔离。命中不再合成，完整流才提交缓存，取消或失败清理临时文件。整篇朗读仅预取下一句，避免无用合成。
- FR-11 缓存音频不默认永久保存：LRU 上限可配（默认 2GB），生词发音与用户收藏句音频优先保留。

## 3. 业务规则

- BR-01 目录来源为已配置供应商的音色列表；目录可用不等同于每个音色均已试听成功。每项可显式试听与测速，失败保留实际错误，不以兜底音色伪装成功。百炼系统音色来自官方静态目录，MiniMax 仅供对照试听，不能设为用途默认值。
- BR-02 免费档失效自动降级下一档并提示，不静默失败不伪造播放。
- BR-03 播放控件有明确状态（加载/播放/暂停/失败），失败给具体原因与重试。
- BR-04 音素级朗读（音标教学）暂不承诺：Web Speech 无 IPA 合成能力，SSML `<phoneme>` 仅 Azure 档支持；无可靠能力时禁用按钮并说明，不把 IPA 交给普通 TTS 读成字母名。

## 4. 实现方案

| 部件 | 方案 | 开源参考 |
| --- | --- | --- |
| 免费档 | edge-tts（Python，多音色），worker 合成落缓存 | rany2/edge-tts（LGPL，注意端点可能失效） |
| 高质量档 | OpenAI TTS（`tts-1`/`gpt-4o-mini-tts`）、Azure TTS（SSML 支持最全） | 官方 SDK |

| 前端播放 | Web Audio + 队列服务（Zustand 单例 store） | - |
| 句级高亮 | 按句合成返回时长 → 播放进度映射句索引 | asbplayer 的时间轴思路 |

## 5. 验收要点

- AC-01 单句朗读起播 P95 < 1.5s（缓存命中 < 200ms）。
- AC-02 整篇朗读高亮偏差 ≤ 1 句；点词打断后整篇队列停止，词读完不自动恢复整篇（用户显式继续）。
- AC-03 edge-tts 不可用时自动降级并标注实际音源，主流程不阻塞。
- AC-04 同一句同音色二次播放不产生合成调用（缓存命中）。

## 6. 统一音色窗口与服务接入

全产品选音色使用 `VoicePicker`：供应商导航、语言筛选、女声/男声/其他分类、名称与 ID 搜索、分页、逐项试听及首播延迟。目录刷新不自动改变用途绑定。语速在弹出式选项中选择，提交音色前可试听选定语速。实时会话独立筛选兼容供应商，不把朗读音色作为端到端会话能力。

从设置打开时使用独立居中窗口，后层设置仍保留；音色列表独立滚动，操作栏固定。Esc、关闭与返回只退出音色窗口，不丢失设置分区及滚动位置。测试默认显示首播延迟，完整诊断保留连接就绪、首音频块与整句完成；无法观测的指标不填零。首播由浏览器 `playing` 事件测量，不能替代人工听感验收。

Azure 与 Edge 收到音频后即可播放，同时写入本地缓存。回合制对话逐句缓冲，顺序播放；端到端实时会话继续使用自己的音频管线。Azure 发音评测默认关闭，在语音设置选定 Azure 凭据并开启后，才显示短句跟读入口；每次录音还需点击发送确认。仅上传本次 0.4～30 秒录音与参考句，不保存原录音，不自动开启额外韵律计费选项。

| 服务 | 开通与取 Key | NEXUS 配置 |
| --- | --- | --- |
| 阿里百炼 | 登录百炼控制台、开通模型服务，在密钥管理创建 API Key；[官方步骤](https://help.aliyun.com/zh/model-studio/get-api-key) | 添加「阿里百炼语音」，填 API Key，地域选择 beijing 或 singapore，必须与 Key 所属地域一致；默认 `qwen3-tts-flash-realtime`，不是云账号 AccessKey ID/Secret |
| Cartesia | 注册 Cartesia 账户，在 [API Keys](https://play.cartesia.ai/keys) 创建密钥并确认可用额度 | 添加 Cartesia，填 API Key，默认 `sonic-3.6`；刷新音色，试听后绑定用途 |
| MiniMax | 注册开放平台，在账户管理的接口密钥页创建按量付费 Key；[官方步骤](https://platform.minimaxi.com/docs/guides/quickstart-preparation) | 添加「MiniMax 对照试听」，使用语音 API 的 Key，不使用 Coding Plan Key；默认 `speech-2.8-turbo`，仅目录试听 |
