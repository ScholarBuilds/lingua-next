# 词库与背单词

## 1. 模块目标

内置权威词典数据与考纲词表，支持背单词、拼写练习与 FSRS 间隔复习；书库、字幕里点词收藏的生词自动带语境进入复习队列，形成"阅读 → 收藏 → 复习"闭环。

## 2. 功能需求

### 查词入口与自测交互

查词输入区使用单条底线；聚焦时底线使用强调色，不叠加输入框内部轮廓。
2026-09-08 本机桌面档检索抽样：经 Vite 代理访问 search 接口，每词连续查询 5 次，
pet/went/per/ab*don/recieve 中位数 12–17 ms，放弃/想/电脑中位数 64–71 ms。
样本不含输入防抖与渲染时间，不代表并发或冷启动性能。当前词头 1,977,707 条、
中文释义 923,749 条；精确与前缀查询已有索引，未引入 Elasticsearch。
输入防抖为 120 ms，回车立即提交；输入法组词期间不提交，输入变化后隐藏旧结果。
查询取消信号传递到 fetch，切换关键词取消旧请求，不将取消显示成网络错误。
中文同匹配档按常用层、义项序、词频排序；后续档排除前档已命中的词，保留各档配额。
中文包含检索通过 `ix_dict_gloss_learner_cover` 覆盖索引缩小扫描范围；迁移可回退，
升级前备份本地数据库。升级后服务预热，每词 10 次接口复测中位数：放弃 32.5 ms、
想 25.5 ms、电脑 30 ms；服务刚启动时有耗时波动，结果不代表冷启动或并发 SLA。
检索、排序与索引迁移使用后端测试验证；旧请求取消使用 QueryObserver 与模拟 fetch
验证。内置浏览器验证连续输入、回车提交及中文结果与当前关键词一致。
界面通过内置浏览器聚焦检查及 UI 守卫验证。

查词使用独立侧栏菜单和 `/dict` 页面，词汇模块保留词书、专项练习、学习报告。
旧 `/vocab?v=dict` 链接迁移到 `/dict` 并保留查询词与选中词，查询历史和工作位置独立恢复。
各处共享词卡将学习状态放在右上角，点击状态选择学习中、困难词或已掌握。
遮挡自测使用空格查看答案、V 打开或关闭词卡、Esc 关闭词卡；数字 1/2/3 标记状态。
正常浏览、听读与遮挡自测共用当前分类成员；全部、未学、学习中、已掌握、困难词均在
标记后保留卡片和队列位置，标签即时更新，允许原位改回。切换分类、场景、搜索或排序后
按最新状态重建成员；模式切换不移除刚标记的词。退出单词本再进入也重新筛选。
分页与后台刷新更新词条内容并追加新词，不因状态变化移走已有词。

验证：`useDeckItems.test.ts` 覆盖状态变更、改回、清除、分页去重和五类筛选；内置浏览器
验证 TV 从学习中标为已掌握后原位保留，切换听读仍在队列，改为困难词后仍保留；
切换分类再返回学习中时词条与队列均移出。

学习状态写入成功后，通过共享请求层通知当前窗口与同源窗口；先更新已有词卡和
查词结果，再刷新词库、场景、复习及练习统计。失败请求不发布状态变更。
词表按规范小写词名关联学习记录，保留词条本身的显示大小写；`I` 等大写词条的
标记在重新查询和统计中一致。自测保留的卡片同样接收状态更新。
回归覆盖大写词条的三类标记、分页缓存更新、取消人工标记和跨窗口通知。

曝光、领取、自测及练习写入均使用小写规范词名。迁移先备份桌面库，再归一历史
词名；大小写重复记录合并曝光次数，保留最近人工标记、复习调度、复习日志和语境。
曝光保存成功后才更新界面，失败显示可重试提示。
验收覆盖 American、North、TV 重复曝光后重新查询、已掌握不被曝光覆盖，以及
迁移幂等性和关联记录保留；相关后端 37 项、前端 63 项测试通过。

验证：前端相关 74 项测试、类型检查、生产构建和 UI 检查通过。
内置浏览器检查独立查词页、右上角状态菜单、空格揭示与 V 打开词卡。

### 2.1 词典数据（系统级）

- FR-01 内置本地词典：音标（美式 IPA）、词性、释义（中英）、词形变化、词频（BNC/COCA 五档文字化展示，位次进悬停提示）、柯林斯星级、考纲标签（四六级/考研/雅思/托福）。
- FR-02 点词查询三层降级：本地词典命中即时显示 → 本地无中文释义时显示英文并提供 AI 补充按钮 → 完全未命中时显示拼写/词形还原候选 + AI 按钮。任何一层不自动调用 AI。
- FR-03 词形还原仅在词典查不到时执行，候选由词典裁决（避免 `saw`→see/锯 歧义）。
  > 2026-09-05：拼写 / 词形候选由全局查词链提供（02 文档 FR-508：`exchange` 七个码、后缀回退、编辑距离），词卡未命中时可跳查词页。

### 2.2 词表与背单词

- FR-04 内置考纲词表：四六级、考研、雅思、托福、牛津 3000 等，词表与词典数据关联。
- FR-05 自定义词表导入：CSV/TSV/JSON，流程为 选择来源 → 解析 → 预览（新增/重复/失败统计）→ 用户确认 → 导入明细。重复词条默认合并且不覆盖学习进度。
- FR-06 背单词模式：看词识义（认识/模糊/不认识三档反馈）+ 拼写练习（qwerty-learner 式键入）；单词发音自动/手动播放。
- FR-07 学习统计：每日新学/复习量、词表进度；不做连续打卡压力设计，复习可暂停可退出。

### 2.3 复习调度

- FR-08 FSRS 调度：每次复习反馈更新记忆状态，生成次日复习队列；复习日志全量保留。
- FR-09 复习卡片带语境：来自书库/字幕收藏的词展示原句、出处（书名·章节 / 视频名·时间点），点击出处跳回原文位置。
- FR-10 生词状态：新词 / 学习中 / 熟悉 / 已掌握 / 暂停；已掌握的词在阅读器中不再高亮标记。

## 3. 业务规则

- BR-01 点击查词 ≠ 收藏 ≠ 掌握，三者独立记录。
- BR-02 生词本与收藏视图是同一份数据，不建第二套存储；词表归属为多对多（一词可属多词表）。
- BR-03 同一词在不同上下文的出现记录独立保存（`vocab_occurrence` 拆表），复习跳转用最近一次语境。
- BR-04 复习算法版本与参数可查可回滚；调度数据格式兼容 FSRS 标准（未来可导出 Anki）。
- BR-05 词典事实与 AI 补充释义分栏展示、来源标识不可混淆。

## 4. 实现方案

| 部件 | 方案 | 开源参考 |
| --- | --- | --- |
| 词典数据 | ECDICT（MIT，340 万词条）导入 PostgreSQL，含音标/词频/考纲标签 | skywind3000/ECDICT |
| 调度算法 | py-fsrs 直接作依赖（FSRS-6），不自研 | open-spaced-repetition/py-fsrs |
| 背单词交互 | qwerty-learner 组件与词库 JSON 格式二开 | RealKai42/qwerty-learner |
| 复习日志模型 | 参考 Anki review log schema | ankitects/anki |
| 词形还原 | spaCy lemmatizer + ECDICT exchange 字段 | explosion/spaCy |
| 长列表 | TanStack Virtual 虚拟滚动 | - |

> [!note] 与旧版的词典数据决策差异
>
> 旧版因权属顾虑弃用 ECDICT，改用 Chinese Open Wordnet × WordNet 逐义项对齐方案（工程量大）。新版为个人学习项目，直接采用 ECDICT（DEC-NEXT-002），WordNet 对齐方案降为未来商业化时的备选。旧版已验证的经验保留：本地命中延迟 10-20ms、例句与译文必须成对存取、词频缺失不显示徽标。

## 6. 验收要点

- AC-01 万级词表列表滚动流畅（虚拟滚动）；本地词典查询 P95 < 50ms。
- AC-02 书里收藏的词次日出现在复习队列，卡片展示原句并可跳回。
- AC-03 复习中断后重进，队列状态一致，无重复扣减。
- AC-04 导入 1 万词 CSV：预览统计准确，失败行有可下载明细。

## 6.1 英文释义的呈现（v11.5 · scholar 反馈）

词卡里中文释义下面那块英文，scholar 看不出是干什么的——是 ECDICT 的 `definition` 字段（WordNet 来源），
与 `translation`（中文释义）是两份不同数据。**保留**：用英语理解英语能避开中文对译的偏差。
问题出在呈现，三处都修：

- FR-364 加**「英文释义」标签**与中文释义区分。原先两份数据挤在同一个「词典释义」标题下，看不出差别。
- FR-365 义项**按词性常用度排序**。WordNet 按数据库顺序排、不按常用度——`simple` 的 `n. any herbaceous plant having medicinal properties`（草药，古义）排在最前，而 ECDICT 的 `pos` 字段明写着 `j:99/n:1`（99% 用作形容词）。这份分布现成的，直接拿来排序，形容词义项提到最前。
- FR-366 WordNet 的 `s.`（satellite adjective，从属形容词）对学习者是天书，归并为 `a.`；`pos` 字段本身也不再裸显示 `j:99/n:1`，翻成「多作形容词 · 偶作名词」，原始值放 title。

> [!note] 判断"要不要留"之前先看它是什么
>
> 这块内容第一眼像是显示故障（英文乱码般的义项、看不懂的 `s.`），
> 但它其实是有价值的数据被排序和标注坑了。**先查清数据来源再决定删留**——
> 直接删掉会丢掉英文释义这个学习价值。
