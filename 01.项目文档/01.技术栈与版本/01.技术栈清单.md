# 技术栈清单

> [!info] 决策依据
>
> 形态与选型理由见 [ADR-001](../02.架构/ADR/ADR-001-产品形态选择Web优先.md) ~ [ADR-006](../02.架构/ADR/ADR-006-AI解释与翻译结果持久化寻址.md)。本清单是执行基线，版本号为立项时的下界，升级走常规依赖更新流程。

## 前端（`web/`）

| 类别 | 选型 | 版本基线 | 用途 |
| --- | --- | --- | --- |
| 框架 | React + TypeScript | 18.x / TS 5.x | SPA 主框架 |
| 构建 | Vite | 6.x | 开发与构建 |
| 样式 | TailwindCSS + shadcn/ui | 4.x | UI 体系，组件源码进仓库可改 |
| 状态 | Zustand | 5.x | 客户端状态 |
| 服务端数据 | TanStack Query | 5.x | API 缓存与请求编排 |
| 路由 | React Router | 7.x | 页面路由 |
| 虚拟列表 | TanStack Virtual | 3.x | 词库长列表 |
| 图书渲染 | foliate-js | main | epub/mobi/azw3/fb2 渲染与 CFI 定位 |
| PDF 渲染 | pdf.js | 4.x | PDF 文章 |
| 视频 | 原生 `<video>` + 自研字幕层 | - | 字幕同步/点读，逻辑移植 asbplayer |
| 实时语音 | WebRTC + Web Audio | 浏览器原生 | Realtime 语音对话 |
| 包管理 | pnpm | 9.x | 遵循全局偏好 |

## 服务端（`server/`，Python 单代码库）

| 类别 | 选型 | 版本基线 | 用途 |
| --- | --- | --- | --- |
| 语言/运行时 | Python | 3.12+ | api 与 worker 共用 |
| 包管理 | uv | 最新 | 依赖与虚拟环境 |
| Web 框架 | FastAPI + Uvicorn | 0.115+ | 业务 API、SSE/WebSocket |
| ORM | SQLAlchemy 2 + Alembic | 2.x | 数据模型与迁移 |
| 校验 | Pydantic v2 | 2.x | DTO 与配置 |
| 任务队列 | arq | 0.26+ | Redis 队列，下载/转写/整篇翻译长任务 |
| 视频下载 | yt-dlp | 最新（滚动更新） | YouTube 及数百站点下载 |
| ASR | faster-whisper（word_timestamps） | 1.x | 字幕转写、词级时间戳 |
| 强制对齐（备选） | whisperX | 3.x | 词级时间戳精度不足时启用 |
| TTS | edge-tts（主，免费多音色）+ OpenAI TTS（高质量档） | - | 朗读与整篇朗读；kokoro 为本地备选 |
| 机器翻译聚合 | translators 库 + 官方 SDK（DeepL/有道） | - | Bing/Google/有道等免费与官方通道 |
| 间隔重复 | py-fsrs | 4.x+ | FSRS 调度 |
| epub 解析 | ebooklib + lxml | - | 服务端分章分句入库 |
| 分词分句 | spaCy（en_core_web_sm）| 3.x | 分句、词形还原、词性 |
| 质检 | ruff + mypy + pytest | - | 遵循全局验证规范 |

## LLM 与语音 AI

| 类别 | 选型 | 说明 |
| --- | --- | --- |
| LLM 网关 | LiteLLM Proxy（独立容器） | 供应商/模型/密钥运行时配置，语义别名路由（ADR-004） |
| 实时语音 | OpenAI Realtime API（WebRTC 直连） | 主路径；pipecat 自建管线为备选（ADR-005） |
| 词典数据 | ECDICT（77 万词条，MIT） | 本地词典兜底 + 音标/柯林斯星级/考纲标签 |

## 数据与基础设施

| 类别 | 选型 | 版本基线 | 用途 |
| --- | --- | --- | --- |
| 数据库 | PostgreSQL | 16 | 业务数据 + JSONB 分析缓存 + FTS |
| 缓存/队列 | Redis | 7 | arq 队列、进度发布、热点缓存 |
| 媒体存储 | 本地卷（Docker volume） | - | 视频/音频/书籍原件，HTTP Range 流式访问 |
| 入口 | Nginx | 1.27 | 静态托管 + API 反代 |
| 编排 | Docker Compose | v2 | 一键启动全部服务 |
| CI | GitHub Actions | - | lint + test + build |

## 明确不引入（首版）

- Kubernetes、消息队列（Kafka/RabbitMQ）、微服务注册发现——单用户规模纯负担。
- MinIO/S3——本地卷足够，云部署时再评估。
- Elasticsearch——PostgreSQL FTS 起步，检索需求升级再评估。
- Java/Spring、Go、Rust 服务——触发条件见 ADR-003 复审条款。
