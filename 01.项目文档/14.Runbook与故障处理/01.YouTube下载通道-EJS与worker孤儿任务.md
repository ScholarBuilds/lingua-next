# YouTube 下载通道：EJS 依赖与 worker 孤儿任务

- 日期：2026-08-17
- 状态：已验证（14 条视频批量导入全链路实测通过）

## 故障一：下载报 bot_check / "The page needs to be reloaded" / "No video formats found"

**现象**：yt-dlp 提取失败，错误轮换出现三种：`Sign in to confirm you're not a bot`、`The page needs to be reloaded`、`No video formats found!`，伴随 WARNING `n challenge solving failed ... JavaScript runtime and challenge solver script distribution`。

**根因**：yt-dlp 2026.x 起 YouTube n-challenge 必须由外部 JS 运行时求解（EJS 机制），缺一不可：

1. 解题脚本包 `yt-dlp-ejs`（PyPI，pip 装 yt-dlp 不自动带）
2. JS 运行时 **deno**（yt-dlp 默认 `js_runtimes: {'deno': {}}` 只认 deno，node/bun 在场也不用）

**修复**：

```bash
cd server && uv add yt-dlp-ejs   # 已入 pyproject（yt-dlp-ejs>=0.8.0）
brew install deno                # 机器级，装一次
```

**验证**：`uv run python -c "...extract_info..."` 能拿到 formats；verbose 日志应出现 `JS runtimes: deno`（而非 `none`）。

**注意**：arq worker 进程的 PATH 必须含 `/opt/homebrew/bin`（deno 所在），launchd/nohup 拉起时 PATH 不全会复现故障。cookies 走凭据库 login_profile 现导（`domain.youtube_login.export_cookies_sync`），与本故障无关。

## 故障二：worker 重启后 ingest 任务变孤儿（状态永卡 downloading）

**现象**：worker 被 kill/重启后，重启前在跑与在队的 `ingest_video` job 丢失：DB `videos.status` 停在 `downloading`（progress 0/60），Redis 队列无对应 job，新 worker 空闲；20 分钟无进度变化、媒体 `.part` 文件 mtime 冻结即可确认。

**为何不能直接 /retry**：`POST /videos/{id}/retry` 仅接受 `failed|ready` 状态，`downloading` 返回 409。

**恢复**（复刻 retry 端点逻辑，绕过状态检查）：

```python
# cd server && uv run python - <<EOF ...
from app.queue import get_queue
from app.db import SessionFactory
from domain.models import Video
# 1) 目标 id 置 status="pending", error/error_kind=None, progress=0，commit
# 2) queue.enqueue_job("ingest_video", vid, _job_id=f"ingest_video:{vid}:{uuid4().hex[:6]}")
#    （换 job id 绕过 arq 结果保留期内同 id 去重）
EOF
```

`.part` 断点续传文件保留在 data/media/videos/，重跑会续传。

**预防**：重启 worker 前先确认无 in-flight ingest（`grep '→ ingest_video' worker日志` 与 `←` 配对）；多代理协作时 worker 的 kill/restart 须先在会话内通报。

## 附：偶发瞬时错误（重试一次即过，无需处理）

- `aria2c exited with code 1` / aria2 `errorCode=2 Timeout`：googlevideo 连接超时，重试即过。
- enrich 报 `LLM 不可用（summary-long/summary）：Request timed out.`：LLM 网关瞬时超时，`POST /videos/{id}/enrich` 重跑即过（支持 `?only=summary|difficulty|phrases|vocab` 单步重跑）。
