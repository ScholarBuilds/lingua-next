# 前端验证方法论

> [!danger] 本文的由来：连续三轮出现「测了等于没测」
>
> 判据选错时，验证不会报错，它会**给出通过**。这比不验证更危险——
> 缺陷被一份看似完整的证据盖住，直到用户在界面上撞见。
> 下面每条都是本项目真实发生过的假通过。

## 1. 判据选择：三类假通过

### 1.1 验「存在」不等于验「可见」

**案例**：从语法分析弹窗点词，词卡确实创建了，`document.querySelector('.wm-card')` 有值，判定通过。
实际上它 `z-index: 95` 被 `z-index: 100` 的弹层整个盖住，用户看不见（FR-347）。

**正确验法**：拿元素中心点回看命中的是不是它自己。

```javascript
// 浮层类改动一律这样验：DOM 里有 ≠ 用户看得见
const r = card.getBoundingClientRect()
const hit = document.elementFromPoint(r.x + r.width / 2, r.y + 30)
const visible = hit?.closest('.wm-card') !== null
```

### 1.2 查询对象根本不在 DOM 里

**案例**：验「关弹窗停朗读」，用 `document.querySelectorAll('audio')` 数在播的音频，
读数是「关前 0 个、关后 0 个」，看着像通过。
实际上 `playUrl` 用 `new Audio()` 创建的元素**从不挂进 DOM**，那个查询永远是空的（FR-350）。

**正确验法**：给原型方法插桩记事件，用行为而不是节点做判据。

```javascript
window.__log = []
const P = HTMLMediaElement.prototype
const [op, oz] = [P.play, P.pause]
P.play = function () { window.__log.push(['play', this.src]); return op.apply(this, arguments) }
P.pause = function () { window.__log.push(['pause', this.src]); return oz.apply(this, arguments) }
// 断言：操作后应出现 pause 事件
```

### 1.3 样式「改了没反应」不看代码要量数值

**案例**：`.ss-card { max-width: 900px }` 想覆盖 `.overlay-card { max-width: 520px }`，
两者同为单类选择器、特异性相同，谁生效取决于 CSS 导入顺序——实测宽度仍是 520px（BR-G-027）。

**正确验法**：量实际几何量，别读代码推断。

```javascript
Math.round(el.getBoundingClientRect().width)   // 一行就定位了
getComputedStyle(el).zIndex                    // 层级同理
```

## 2. 验证环境的异常，先当真实缺陷查

> [!warning] 最容易放过缺陷的一步
>
> 浏览器面板页签 `visibilityState` 常为 `hidden`，此时 **rAF 被整体冻结**。
> 卡拉OK高亮采样一直为空，守卫插桩显示条件全满足，一度判定为"验证环境限制，绕过去"。
>
> 但它同时是**产品缺陷**：用户把页面切到后台再切回来，高亮一样停摆（BR-G-025）。
> 加 `timeupdate` 双通道兜底后，两个问题一起解决。

**规矩**：验证环境暴露的异常，先假设是产品缺陷去查；确认只是环境限制后，再想办法绕，并在报告里如实写明「未实测」。

## 3. 已知的环境限制清单

| 现象 | 原因 | 应对 |
| --- | --- | --- |
| rAF 驱动的效果不动 | 页签 hidden 时 rAF 冻结 | 先判断是不是产品也该兜底；纯验证问题就换 `timeupdate` 采样 |
| DOM 几何量全是 0 | 面板 hidden 时整棵树几何为 0 | 先 front 页签，或直接看截图 |
| `curl https://<局域网IP>` 返回 000 | 沙箱 curl 走 HTTP 代理，CONNECT 隧道下 TLS 握手超时 | 加 `--noproxy '*'` |
| 麦克风相关一律拿不到 | 面板不授予设备权限 | 如实标注「未实测」，交给人工在本机跑 |
| 改了后端没反应 | uvicorn 未开 `--reload`，跑的是旧代码 | 重启并 `pgrep` 复核残留（`pkill` 可能一个没杀掉） |
| 装完新依赖首次按键无响应 | vite 重新预打包触发整页重载，按键落在重载窗口里 | 等页面稳定再测 |

## 4. 交付前的自检

- [ ] 浮层类改动：验过**可见性**而不只是存在性？
- [ ] 播放/停止类改动：判据是**行为事件**而不是 DOM 节点？
- [ ] 样式类改动：**量过实际数值**而不是读代码推断？
- [ ] 出现异常时：先当产品缺陷查过，才归因到环境？
- [ ] 确实没验到的部分：报告里**明确写了「未实测」**及原因？
