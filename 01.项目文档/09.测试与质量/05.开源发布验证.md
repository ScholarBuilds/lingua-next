# 开源发布验证

本次公开发行从当前源码建立独立的新 Git 历史。本机开发库、历史提交、原始截图、账号及密钥不作为发布输入。目标仓库为 `sortbyiky/lingua-next`。

## 发布边界

- 打包入口禁止导出服务凭据与解密密钥，使用者自行在设置中配置服务。
- 初始内容通过白名单构建全新数据库，只有书籍、章节、段落、句子、原创视频及字幕表。
- 包含 40 本书、1,638 个章节、61,467 个段落、139,016 个句子、338 篇讲义和一段原创双语入门视频。
- 第三方视频仅保留来源链接。私人系统截图不公开，公开讲义相应位置注明移除原因；本机资料不改变。
- 首次桌面启动自动导入，文件校验失败中止；重复导入不覆盖用户文档，ID 冲突保留用户数据。
- 原创代码按 MIT 准备；第三方工作流、模型和书籍保留各自许可，不能统一视为 MIT。

## 验证证据

- 发布副本后端相关测试：50 项通过，包括空库导入、幂等、文档保留、私人表拒绝及路径逃逸拒绝。
- 发布副本前端：135 个测试文件、1,655 项测试通过；类型检查、CSS/滚动检查和生产构建通过。
- 全新数据库接口：书架、视频、英文字幕、双语句子及五类讲义接口均为 200，视频 Range 请求为 206。
- 全新数据库的 provider_credential、model_deployment、user_pref、config_audit 均为 0 条。
- 实际服务凭据仅在内存解密比对，未出现在发布副本；扫描报告不记录真实密钥。
- Gitleaks 8.30.1：仅对已核实的测试假值及公开协议常量作精确值排除后，发现数为 0。
- 已补充现有前端和桌面 pnpm 锁文件，保持依赖可复现。
- 治理 standard/warn L1 通过；该审计不代替运行验证和内容许可边界。
