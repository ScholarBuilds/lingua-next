# shadcn 落地与弹层迁移记录

2026-08-17 完成组件基建升级第一批落地，对应 [03.组件库选型与组件规范](./03.组件库选型与组件规范.md) 的第 2 层（shadcn 基座）。

## 1. 引入方式

- `web/components.json` 手写（style: new-york，css 指向 `src/styles/app.css`，别名 `@/`），未跑 `shadcn init`（避免 CLI 改写全局 CSS）。
- `pnpm dlx shadcn@latest add button select dialog dropdown-menu popover switch tooltip tabs input textarea slider separator scroll-area sonner alert-dialog command` 拉取源码到 `web/src/components/ui/`。
- CLI 拉的是 React 19 风格源码，两处适配：
  - `dialog.tsx` / `alert-dialog.tsx` 的 Overlay 补 `forwardRef`（React 18 下 Radix Presence 传 ref 会告警）。
  - `sonner.tsx` 去掉 next-themes 依赖（主题跟随 `data-theme`，直接读映射后的 `--popover` 变量）。
- 依赖：`radix-ui`（合包）、cmdk、sonner、clsx、tailwind-merge、class-variance-authority、lucide-react、tw-animate-css（dev）；`vite.config.ts` 加 `@` 别名，tsconfig paths 原有。

## 2. 令牌映射桥（app.css）

shadcn 语义变量全部映射到 tokens.css，深浅色自动跟随，无第二套主题：

| shadcn | token |
| --- | --- |
| --background / --foreground | --bg-app / --ink |
| --card / --popover | --bg-surface |
| --primary / --primary-foreground | --accent / --on-accent |
| --secondary / --muted | --bg-sunken |
| --muted-foreground | --ink-muted |
| --accent（悬停底色语义） | --bg-hover（避开品牌 --accent 同名冲突） |
| --destructive | --err |
| --border / --input / --ring | --border / --border-strong / --accent |
| radius sm/md/lg | --radius-sm/md/lg（经 --br-* 桥接避免 @theme inline 自引用） |

`@custom-variant dark` 绑定 `[data-theme="dark"]`；Radix 弹层 z-index 统一压过 `.theme-toggle`(90) 与旧 `.overlay`(100)。

## 3. 两个踩坑（已修）

1. **无层级重置压制工具类**：tokens.css 的 `* { margin:0; padding:0 }` 与 `button { background:none }` 原为无层级规则，按 CSS 级联规则压过 Tailwind utilities 层，导致 shadcn 组件 `p-*`/`bg-*` 全部失效（开关透明、弹窗无内边距）。修复：元素级重置移入 `@layer base`，项目类选择器保持无层级不受影响。
2. **`.grid` 类名冲突**：书架的 `.grid`（150px 列）与 Tailwind `grid` 工具类同名，DialogContent 布局被打成三列。修复：书架类改名 `.book-grid`。

## 4. 弹层迁移清单（全部 portal 渲染，根治容器裁切）

| 位置 | 原实现 | 现实现 |
| --- | --- | --- |
| 设置页 Sel 下拉（场景音色/凭据/模型/看板娘模型） | 绝对定位自绘菜单（被 .cwrap 裁切，即语音场景绑定截图 bug） | Popover + Command 组合框：>8 项或可手输时自带搜索，手输走「使用『xxx』」行 |
| 设置页 Switch | 自绘 .switch | shadcn Switch（旧 API 保留：on/onChange） |
| 凭据添加/编辑覆盖层 | .overlay 自绘 | Dialog |
| 高级参数（temperature/reasoning_effort） | .overlay | Popover（锚定按钮） |
| 添加降级 / 审计日志 / 实时语音会话参数 | .overlay | Dialog |
| 书架删书确认（含 409 强删流） | .overlay 自绘 | AlertDialog |
| 文章删除确认 | window.confirm | AlertDialog |
| 阅读器 PlayerBar 音色菜单 | 绝对定位菜单 | DropdownMenu（side=top） |
| 阅读器版本浮层 VersionsButton | 绝对定位 .ver-pop（面板滚动容器内有裁切风险） | Popover |

## 5. 设置页子导航重设计

`SettingsPage` 子导航分组：服务配置（模型/语音/翻译）· 个人偏好（阅读与外观）· 系统（用量/数据）；宽度 220→200px，item 图标 + 圆角激活态，标题区加「返回应用」箭头。

## 6. 导航布局双模式

- `prefs.ui.navLayout: 'side' | 'top'`（默认 side），设置 · 阅读与外观 · 外观分组新增「导航布局」，切换即时生效，服务端整包持久化。
- `top` 模式：48px 顶部横条（logo + 五入口 + 右侧主题/设置），内容区全宽。
- 沉浸式路由（`/read/*`、`/video/:id`、`/talk/session*`）在 top 模式下隐藏全局横条，页面自带 topbar 独占一条（不叠两条），返回走面包屑。
