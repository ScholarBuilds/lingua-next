# 生活英语场景百科与场景课退役说明

2026-09-07 起移除生活英语场景百科与场景课。词汇页面不再显示百科词本，侧栏不再显示场景课；页面、课程内容、独立原型构建与专用 API 均已删除。

普通词汇卡片、考纲词书、其余场景词本、听读与语法功能继续使用原实现。旧页面地址使用通用未知路由回到首页，词汇菜单忽略百科页面的旧位置记忆。

数据库迁移仅按专用 catalog_key 删除百科词本及目录词条；关联短文解除词本归属，生词与练习记录不变。历史笔记表不再提供界面或接口。历史设计和课程样章可在 Git 提交 `4e5bf7c` 中查阅。
