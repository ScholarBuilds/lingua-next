# 信息架构与核心页面

> [!tip] 原型对照
>
> 每个页面有可在浏览器打开的高保真原型（`design/mockups/`，深浅色可切换）。原型是布局与交互的视觉基准，开发时按原型 + 本文实现。

## 1. 应用外壳

```
┌──┬──────────────────────────────────────┐
│侧│ 顶栏（位置 · 标题 · 状态 · 动作）        │
│栏├──────────────┬───────────┬───────────┤
│导│ 上下文侧栏     │  内容主区   │ 学习面板   │
│航│ (目录/词表/    │ (纸感画布/  │ (按需出现, │
│栏│  字幕列表)     │  视频/对话) │  可折叠)   │
└──┴──────────────┴───────────┴───────────┘
```

- **左侧带标签侧栏（232px 展开 / 64px 折叠，清岩浅壳）**（CR-006 D3，2026-09-02 起）：顶部一个搜索形态的 ⌘K 入口；「今天」单独一项；按活动分两组——学习（阅读 / 视频 / 词汇 / 语法 / 对话）、创作（工坊）；底部固定「任务」（带在跑 + 失败徽标，展开态下面直接列出正在跑的几条，即原右下角 RunningDock 收进来的形态）、设置、主题、收起。没有登录、没有退出、没有「管理」组。折叠态只留图标，组标题退回分隔线。
- **⌘K 命令面板**（D6）：任何页面 ⌘K / Ctrl+K 打开，搜书、视频、生词，跳页面，执行导入 / 复习 / 新建画布 / 设置 / 主题 / 收起导航；遮罩与 Esc 走 `components/Overlay`，列表走 cmdk。条目只列真的接了处理器的（`components/commandItems.ts`）。
- **任务与管线一个入口**（D4）：侧栏只有「任务」；任务中心页有两个视图，列表按状态筛、「管线总览」按域看健康；`/pipeline` 重定向到后者，域页与主体下钻页深链保留。
- **上下文侧栏**：随页面变化（阅读器=章节目录、词库=词表列表、视频=字幕列表侧挂右侧）。宽度可拖拽记忆，分隔条键盘可调。
- **学习面板（右，336px）**：点词/点句的常驻形态；可折叠，折叠后学习内容改为锚定弹卡。两形态共用数据与状态机，用户偏好切换。
- 打开书籍章节不改变图标栏选中项（来路决定返回落点，`ReadingOrigin` 枚举唯一定义）。

## 2. 页面清单与路由

| 路由 | 页面 | 原型 |

| `/`（默认首页） | 今天：接着来（书 / 视频 / 对话各一张）· 在跑 · 最近加入 · 到期复习与本周时长 | workbench.html |

## 3. 各页面关键交互规范

### 3.1 精读工作台（reader.html）

- 三栏：句子级目录（250px）/ 纸面画布（≤660px 居中）/ 句子面板（336px）。
- 点词 = 高亮 + 朗读该词 + 出学习卡；点句（行号区）= 高亮 + 朗读 + 右面板刷新；三件事作为一个动作整体变化。
- 学习卡两级：主卡 + 替换式速查小卡，Esc 分级关闭；卡内再点词替换小卡自身，不叠层。
- 重复点击同一词只重新朗读不重建卡（防版面抖动）。
- 顶栏：原文/双语/译文三态 seg（切换保持滚动位置）、词组标记开关、排版设置、书内搜索、**AI 陪读按钮**（唤起语音会话注入全文上下文）。
- 底部悬浮朗读条：上一句/播放/下一句、音色名、倍速、回到朗读位置；正在朗读的句子在目录中用喇叭图标标识。

### 3.2 书架（shelf.html）

- 顶部"继续阅读"横幅直达上次位置——打开应用的第一眼就是"接着读"。
- 按状态分段（在读/未开始/已读完），不按来源分堆；书与文章同卡片、角标区分；封面叠进度条（仅 >0 显示）。
- 导入卡内联在网格中（拖放 epub/pdf/txt/md 或粘贴 URL），不是藏在菜单里的功能。

### 3.3 词库（vocab.html）

- 左：统计（待复习/今日新学/连续天数）+ 词表列表；右：纸面底的大闪卡。
- 闪卡：单词 + 音标 + 发音 →（空格翻面）→ 释义 + 语境句（来自用户读过的内容，出处可跳回）→ 忘记/模糊/认识三档（1/2/3 键），每档标注 FSRS 下次间隔。
- 拼写模式、标熟、跳过为次级操作；快捷键常驻底部提示。

### 3.4 视频学习（video.html）

- 左：视频 + 视频内双语字幕（词可点）+ 控制条（逐句跳转/AB 循环/逐句暂停/倍速）；右：字幕列表（时间戳 + 双语，当前句高亮 + 喇叭，点击跳转，生词/词组标记与阅读器同体系）。
- 字幕点词自动暂停（可配置），学习卡与阅读器同一套。
- 字幕轨可切换（官方/Whisper 转写/翻译），来源 chip 常显。

### 3.5 AI 语音对话（talk.html）

- 中央对话流：AI 气泡（英文 + 可折叠中文提示）、用户气泡（转写文本 + 温和的表达反馈：优化建议 warn 色 / 自然 ✓ ok 色）、AI 说话中显示波形 + "开口即可打断"提示。
- 底部：大麦克风按钮（脉冲光环表示聆听中）、文字输入切换、字幕开关；状态文字明示当前会话状态。
- 右面板：场景任务清单（完成态可视）、关键句（可播）、本轮生词、会后转写说明。
- 顶栏常显：场景 + 难度 + 计时/上限 + 结束按钮——时长与费用边界永远可见。

## 4. 全局交互约定

- 快捷键：`空格` 播放暂停（阅读器/视频/闪卡语境各自适配）、`←→` 上下句、`Esc` 分级关闭、`⌘K` 全局命令面板（后置）；快捷键中心集中管理，冲突检测指出具体冲突项。
- 所有异步操作有 骨架/进度/失败重试 三态；长任务（下载/转写/整篇翻译）进全局任务托盘（顶栏角标），不阻塞当前页。
- 空状态必须给"下一步动作"（导入/去书库挑一本），不出现裸空白。
- 通知不含学习内容原文，只给类别 + 数量 + 跳转。
