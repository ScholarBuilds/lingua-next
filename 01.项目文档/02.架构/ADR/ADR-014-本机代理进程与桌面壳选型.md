# ADR-014：本机代理进程用 Electron 壳装现有 SPA

- 状态：accepted；贾维斯专属进程与窗口部分已被 [ADR-018](ADR-018-移除贾维斯专属运行时.md) 替代
- 日期：2026-09-02
- 决策人：scholar（按 [CR-007](../../../00.需求文档/07.需求变更/07.CR-007-产品形态扩展为个人本地工作台.md) §6 拍板 Q1、Q2）
- 修订：补充 [ADR-001](ADR-001-产品形态选择Web优先.md)（Web 优先，可选桌面壳）；2026-09-02 执行内核拆出为 [ADR-015](ADR-015-贾维斯执行内核选型.md)，本文只管壳

## 背景与约束

CR-007 要的四件事——全局快捷键、页面不在前台时常听唤醒词、屏幕捕获与输入注入、读钥匙串——浏览器标签页一件都做不到。需要一个本机常驻进程。候选：

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| Tauri 2 壳 | 现有 SPA 装进 Tauri 窗口；官方插件 global-shortcut / tray / notification / opener | 多一层 Rust 构建；渲染引擎换成系统 WebView（macOS 是 WKWebView，Safari 内核），自定义能力要写 Rust |
| **Electron 壳** | 同一思路，自带 Chromium；主进程 TypeScript | 包体 150 MB 起、内存多一两百 MB |
| Python 菜单栏守护 | rumps + pynput + sounddevice，与 server 同栈 | 没有窗口，SPA 仍在浏览器里；页面与守护之间还要再架一条本地通道 |

这个工作台只装在 scholar 一台电脑上，包体与内存对它没有成本；栈是 TypeScript + Python，不想为壳引入 Rust。

## 决策

1. **Electron 壳**。四条理由，每条都比 Tauri 省下来的体积更要紧：
   - 渲染引擎与开发环境一致（开发看 Chrome，壳里跑的还是那个 Chromium），Chromium 版本随 Electron 钉死，不随系统升级变。
   - 主进程是 TypeScript，进同一个 pnpm workspace（`desktop/`），不引入新语言。
   - 电脑操控与助理要的系统能力它自带：`desktopCapturer` 截屏、`globalShortcut`、`Tray`、`safeStorage`（钥匙串加密）。
   - 操控专用浏览器可以嵌在工作台里：`WebContentsView` 装被操控的页面，Playwright 走 CDP 直接接上，原型里的「屏幕预览」是真页面而不是截图流。Tauri 做不到。
2. **窗口加载的 URL 与浏览器打开的是同一个本地地址**（生产 `http://127.0.0.1:8080`，开发 `http://127.0.0.1:5173`），不把前端打进壳里。前端只有一份，`/api` 相对路径与 cookie 行为不变，壳只贡献系统入口。
3. **业务台账与语音服务留在 Python，执行内核的选型见 [ADR-015](ADR-015-贾维斯执行内核选型.md)**（2026-09-02 拆出：Open Interpreter Rust App Server，审批与权限装在内核协议上）。壳负责全局快捷键、麦克风、权限申请、托盘、通知、急停与三个辅助窗（刘海 / overlay / 审批），三档模式的真源在服务端 `GET|PUT /jarvis/mode`（CR-010 D-5）。
4. **电脑操控第一版只做浏览器范围**（Playwright 驱动专用浏览器）；桌面范围（macOS 辅助功能 + 屏幕录制）延到 CR-007 P7。
5. **先做完 web 端，最后套壳**（CR-007 分期 P7）。但在 CR-006 P2 之后、CR-007 动 UI 之前，花半天做一个空壳探针：空 Electron 窗口加载开发地址，过一遍麦克风、文件拖入书架、导出下载、外链、画布。探针的产出不是壳，是 web 端的两条约定（见下）。

## 对 UI 显示与交互的影响（scholar 2026-09-02 问的）

布局与样式不会变：页面还是那一份 HTML/CSS/JS，引擎还是 Chromium。要动手的只有桌面壳自己的行为差异，按 `web/src` 实际用到的 API 扫出来（文件数）：

| 用到的东西 | 文件数 | 在 Electron 里 | 要做什么 |
| --- | ---: | --- | --- |
| `window.open` / `target="_blank"` 外链 | 3 / 12 | 默认开一个新的 Electron 窗口，不是系统浏览器 | **web 端先收成一个 `openExternal(url)` 助手**；壳里 `setWindowOpenHandler` 交给 `shell.openExternal` |
| `<a download>`、`URL.createObjectURL` 导出 | 13 / 20 | Chromium 下载器在，默认弹系统保存框 | **web 端先收成一个 `saveFile()` 助手**；要静默存到固定目录时壳接 `will-download` |
| HTML5 文件拖放（`dataTransfer.files`） | 11 | 与 Chrome 一致 | 不用改 |
| `getUserMedia` 麦克风 | 2 | 要 `NSMicrophoneUsageDescription` 与 `systemPreferences.askForMediaAccess` | 壳里声明；探针第一项 |
| `MediaRecorder` webm、元素全屏、`AudioContext`、`EventSource`、`WebSocket`、`field-sizing` 等 | — | 与 Chrome 一致 | 不用改 |

另外两条：⌘W / ⌘Q 在壳里是原生关窗与退出，页面快捷键（⌘K、⌥空格）不受影响；助理 HUD 按「页面在前台时按键说话」设计，全局唤醒是壳加上去的能力，不能反过来假设页面不在前台也能听。

## 后果

- 好：一份前端两处开（浏览器与壳），壳的代码量只有系统入口；执行器与审批链路不因换壳而分叉；渲染零差异，前端不必为壳做任何适配。
- 坏：包体与内存；Electron 的大版本升级要跟（每 8 周一个大版本，安全补丁只覆盖最近三个）。
- 备选：Tauri 2 仍可行，代价是 WKWebView 那一套差异（录音 mime、元素全屏、下载、拖放拦截）与 Rust；本 ADR 首版曾选它，那份差异清单留在 git 历史里。

### web 端的两条约定（同日，STD-UI-013）

`web/src/lib/shell.ts`：`openExternal(url)` 与 `saveFile(blobOrUrl, filename)`。收编了四处用 `window.open` 触发下载的地方（词库 CSV / APKG、批注导出）和十六处手搓的下载锚点；一处真外链（视频导入对话框的「打开频道」）改走 `openExternal`。声明式的 `<a target="_blank">`（12 个文件）与 `<a href download>` 不动。

### 壳落地（2026-09-02，CR-007 P7）

决策 5 说的「web 先做完再套壳」到这天兑现：`desktop/src/main.ts` 加了全局 ⌥Space（`globalShortcut`，拉窗口到前台后 IPC 到页面，页面用同一个开关开口）、托盘（`assets/trayTemplate.png` 模板图，菜单：打开 / 说话 / N 个动作等你点头 / 念早报 / 退出，角标随待确认数变）、系统通知（页面经 `reportToShell` 每次状态变化上报，数字涨了弹一条，点了 IPC `shell:navigate` 回那一页）、关窗不退出、可选自启（`LINGUA_AUTOSTART=1` 拉起 API 与 worker，日志 `data/logs/`）。页面侧 `web/src/lib/shell.ts` 多三条钩子（浏览器里空操作），`components/ShellBridge.tsx` 只在壳里轮询待确认数。探针加 5 项到 14 项全过。
唤醒词没做：常听要本机 KWS 模型（openWakeWord 一类）与常驻麦克风，D5 第 6 条要求识别在本机、按下或唤醒后才开流；现在按住 ⌥Space 已经够用，等有真实需求再评估，不为了「贾维斯」四个字先塞一个常驻进程。

### 贾维斯统一入口修订（2026-09-02）

CR-008 已补本机常听；CR-009 后续确认把交互再收成一个全局贾维斯按钮。Electron 接缝的 `requestJarvisPermissions` 只申请壳自身的麦克风权限；辅助功能和屏幕录制属于真正执行桌面动作的 `CuaDriver.app`，状态从 `cua-driver permissions status --json` 读取，申请走 `permissions grant`。贾维斯语音主路只复用火山实时会话的 VAD 与 ASR，不转发该模型的回复或音频；ASR 终稿只交给 Open Interpreter 一次，引擎结果经现有单向 TTS 播报，播放期间暂停麦克风上行。火山不可用时降级到 CR-008 本地 VAD 链路。不请求系统音频录制；macOS TCC 仍必须由人授予。应用内执行默认完全接管、不逐步审批，对应风险缓解为执行流全可见、忙碌拒绝排队与 HUD / 托盘 / `⌘/Ctrl+Shift+Esc` 三处急停。
