# 用搜索和路径定位设置：返回、帮助与层级导航

找不到一个设置时，最有效的动作不是把整句中文逐字翻译后塞进搜索框，而是先判断你要找的是功能名称、动作、结果还是故障原因。系统设置内的搜索、Spotlight、页面内搜索和帮助按钮解决的是不同问题；选对入口，英文再不熟也能很快缩小范围。

> [!info] 本篇完成后，你会有一条可复述的定位路径
>
> `Open System Settings → search or choose a category → open the relevant page → read the description → check the current state.`
>
> 这条路径的重点不是背箭头，而是每一步都知道自己在验证什么。

## 四种“搜索”不要混用

macOS 里常见的搜索入口至少有四种。它们都可能显示一个放大镜图标，但搜索范围和结果完全不同。

| 入口 | 常见英文 | 它搜索什么 | 适合什么问题 | 不适合什么问题 |
| --- | --- | --- | --- | --- |
| 系统设置侧边栏顶部 | `Search` | 设置页面、设置项和相关关键词 | “DNS 在哪里？”“如何找到通知？” | 在所有文件里找一份文档 |
| Spotlight | `Spotlight`, `Search Results` | App、文件、系统功能和建议 | “打开系统设置”“找到某个文件” | 精确理解当前页面的一个开关 |
| 当前 App 的搜索 | `Find`, `Search` | 当前应用的内容或列表 | 在邮件、浏览器、设置列表里找文字 | 跳转到另一个系统类别 |
| 帮助入口 | `Help`, `Learn More` | 对当前功能的说明、支持文章或解释页 | “这个选项影响什么？” | 直接替你执行设置 |

所以，“我找不到 Wi-Fi 的 DNS”最合理的第一步是进 **System Settings**，再使用侧边栏搜索或按 `Wi-Fi → Details… → DNS` 的层级寻找。把 `DNS` 输入 Spotlight 可能会找到帮助内容或其他结果，但不能保证把你带到当前连接的网络详情。

## 先把中文意图变成可搜索的英文核词

系统界面搜索最擅长匹配稳定的页面名、按钮名和选项名，不擅长理解很长的自然语言。搜索前，把中文需求压缩成一个或两个核心英文词，会比整句翻译更稳定。

| 中文意图 | 不建议直接搜索 | 建议的英文核词 | 进入页面后还要找什么 |
| --- | --- | --- | --- |
| 改 Wi-Fi 的 DNS | “网络不好怎么修” | `DNS` 或 `Wi-Fi` | `Details…`, `DNS Servers` |
| 不让某 App 访问照片 | “关闭照片权限” | `Photos` 或 `Privacy` | `Photos`, `Allow` 或开关状态 |
| 调大文字 | “字体很小” | `Text Size` 或 `Display` | `Larger Text`, `Accessibility` |
| 让 Mac 不自动锁屏 | “不要自动锁屏” | `Lock Screen` | `Turn display off`, `Require password` |
| 关闭开机自启 | “开机自动运行” | `Login Items` | `Open at Login`, `Allow in the Background` |
| 连接蓝牙键盘 | “键盘连不上” | `Bluetooth` | `Pair`, `Connected`, `Not Connected` |

这里的 `core word` 不是正式的系统术语，而是你自己用来缩小搜索范围的“核词”。例如中文的“开机自启”可能对应 `Open at Login`，也可能对应 `Allow in the Background`。先用 `Login Items` 找到页面，再用完整说明区分两者，不能看到任何“background”都理解成“开机启动”。

## 路径是有方向的，不是一个长名称

软件教程常把路径写成 `General > Language & Region`。这个符号表示“从外层入口进入内层页面”，不是输入框里应该原样键入的文本。

| 路径写法 | 实际动作 | 自然英文说法 |
| --- | --- | --- |
| `General > Storage` | 先选择 General，再进入 Storage | `Open General and select Storage.` |
| `Wi-Fi > Details… > DNS` | 打开 Wi-Fi，进入当前网络详情，再选 DNS | `Open Wi-Fi, choose Details, and then open DNS.` |
| `Privacy & Security > Location Services` | 进入隐私与安全，再查看位置权限 | `Go to Privacy & Security and select Location Services.` |
| `Accessibility > Display > Text Size` | 进入辅助功能中的显示设置 | `In Accessibility, open Display and adjust Text Size.` |

英语中的 `go to`、`open`、`choose` 和 `select` 都可以用于路径，但语气有细微差别：

- `go to` 强调去某个页面或区域，适合较宽泛的方向。
- `open` 强调打开一个页面、弹窗或详情。
- `choose` 适合从多个可见选项中作出选择。
- `select` 适合在侧边栏、列表、菜单或项目中选中一个项目。

如果你不确定用哪一个，下面这个句型最稳妥：

> `In System Settings, select [category], then open [item].`

它既说明了起点，也明确了外层和内层关系。

## 界面实例：在总览页找到搜索和返回入口

总览页里有三个容易被忽略的导航线索：左上方的后退箭头、侧边栏顶部的 `Search`，以及右侧内容区的层级项目。它们分别解决“回到哪里”“现在怎样找”“下一层有什么”。

| 界面表达 | 它的作用 | 使用时的判断 |
| --- | --- | --- |
| `Search` | 在系统设置范围内找页面和设置项 | 输入短核词；结果出现后仍要读说明句确认。 |
| `Go Back` | 回到刚才的页面层级 | 回退的是导航历史，不一定回到类别总览。 |
| `Go Forward` | 在已经回退后再向前 | 没有回退历史时通常不可用。 |
| `Help` | 打开当前 App 的帮助资源 | 用来理解概念，不能替代对当前状态的核对。 |
| `Learn More…` | 打开与当前设置相关的解释 | 三个点提示会进入更多内容。 |
| `Show Detail` | 打开某一条目自己的详情 | 必须先确认这一行对应的对象。 |

`Go Back` 和 `Back` 都可以理解为“返回”，但不要把它们等同于“撤销修改”。后退只改变你看到的页面，不能撤销已经保存的系统设置。英语里若要表达撤销或恢复，应使用 `undo`、`revert`、`restore`，而不是 `go back`。

## 返回路径：页面返回、状态恢复和操作撤销是三件事

用户在英文系统里很容易看到 `Back` 就安心，以为自己已经“改回去了”。其实这至少有三种完全不同的动作。

| 动作 | 英文 | 它改变什么 | 例句 |
| --- | --- | --- | --- |
| 返回上一页 | `go back` | 当前导航位置 | `I went back to the Wi-Fi page.` |
| 取消未确认的选择 | `cancel` | 正在进行的弹窗或编辑 | `I canceled the change before it was applied.` |
| 改回旧值 | `change it back` / `restore` | 已经保存的设置值 | `I changed the option back to its previous value.` |
| 撤销最近操作 | `undo` | 可撤销的最近编辑 | `Undo is not available for every system setting.` |

网络和隐私页面通常会在切换开关后立即生效。此时你即使点 `Go Back`，设置仍然保留。正确的恢复步骤是回到同一控件，把它改回原值，然后重新打开页面确认状态。例如：

> `I went back to the previous page, reopened the setting, and changed the switch back to off.`

这句话包含了导航、验证和恢复三个动作，因此比 `I went back` 更准确。

## 找到页面以后，怎样确认“就是它”

搜索结果或侧边栏只是第一层。进入目标页后，至少做三次核对：标题核对、说明核对、控件核对。

1. **标题核对**：页面名称是否与需求一致？例如 `Screen Time` 不是 `Lock Screen`，虽然两者都和屏幕有关。
2. **说明核对**：灰色说明里有没有描述你真正关心的对象？例如自动加入网络、通知预览、应用访问照片的条件不同。
3. **控件核对**：找到的是开关、详情入口，还是不可操作的状态文字？它决定下一步是否可能改变设置。

可以把核对过程说成一段英文：

> `I found the page through Search. The title matches the setting I need, and the description mentions the device and condition I want to check. I have not changed the control yet.`

这段话适合向他人求助。它告诉对方你已定位到正确页面，读过说明，也还没有误改设置。

## 遇到没有结果或结果太多时

搜索失败本身也是信息。不要立刻换十个无关单词；按下面的顺序排查，效率更高。

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 没有结果 | 用的是中文意图，不是界面词；或名称随版本变化 | 换成更短的英文核词，如 `VPN`、`Location`、`Keyboard` |
| 结果太多 | 核词太宽，如 `security`、`display` | 加第二个词，如 `FileVault`、`Text Size` |
| 找到的页面没有目标控件 | 控件在详情页、弹窗或不同设备条件下才显示 | 阅读说明，找 `Details…`、`Advanced…`、`More` 或条件提示 |
| 控件是灰色的 | 缺少权限、设备、网络或账户条件 | 搜索或阅读 `requires`、`available when`、`sign in` |
| 教程路径不同 | 资料版本与本机不同 | 保留功能名，按本机页面标题和说明重新定位 |

> [!tip] 把失败的搜索也记录下来
>
> 记录“我搜了什么、看到了什么、为什么排除”的过程很有价值。例如：`I searched for VPN, but the result was a network page rather than the account page I expected.` 这类句子能帮助你建立自己的软件英语词义边界。

## 两个完整操作案例

### 案例一：用搜索找到“登录项”而不关闭任何程序

1. 在 System Settings 左侧顶部的 **Search** 输入 `Login Items`。
2. 选择与 **Login Items & Extensions** 对应的结果。
3. 进入后辨认 `Open at Login` 与 `Allow in the Background` 两类文本，先不要移除任何项目。
4. 读出两者的区别：前者关心登录时打开，后者关心后台是否允许运行。
5. 用英语报告：`I searched for Login Items and reviewed the startup and background options. I did not remove or disable anything.`

这里的 `reviewed` 表示认真查看，而不是“随便看了一眼”。`remove or disable` 同时覆盖“从列表移除”和“禁止后台活动”两种可能动作。

### 案例二：从 Wi-Fi 页进入 DNS，再安全返回

1. 选择 **Wi-Fi**，只确认当前网络所在的行。
2. 点击 **Details…**，阅读详情页中的分组名称。
3. 进入 **DNS**，只查看已有的服务器或搜索域，不新增、删除或拖动条目。
4. 用 `Go Back` 返回 Wi-Fi 详情，再返回 Wi-Fi 总览。
5. 最后确认当前网络仍显示连接状态。
6. 用英语描述：`I followed the path Wi-Fi, Details, and DNS to review the name-resolution settings. I went back through the same path without editing any entries.`

这句话使用 `name-resolution settings` 来解释 DNS 的功能，而没有把技术细节错误地说成“网络密码设置”。

## 把一条路径记成可迁移的语言

不要把 `Wi-Fi → Details… → DNS` 记成一串孤立名词。把路径写成“目标、入口、层级、动作”四个部分，换到别的页面时依然能用。

| 组成 | 要回答的问题 | Wi-Fi 示例 | 隐私示例 |
| --- | --- | --- | --- |
| 目标 | 我想检查什么？ | 名称解析是否正确 | 某个 App 是否能访问照片 |
| 入口 | 从哪个大类开始？ | `Wi-Fi` | `Privacy & Security` |
| 层级 | 还要进入哪一层？ | `Details…`, `DNS` | `Photos` |
| 动作 | 我是查看、改变还是恢复？ | `review`, `add`, `remove` | `allow`, `turn off`, `check` |

把它们连成语言时，可以按不同目的选不同句型：

```text
To check [goal], open [category] and select [item].
To change [setting], go to [category], open [detail], and choose [value].
After checking [item], go back and confirm that [state].
```

例如：

- `To check the DNS configuration, open Wi-Fi and select Details, then open DNS.`
- `To change a photo permission, go to Privacy & Security and open Photos.`
- `After checking the network details, go back and confirm that Wi-Fi is still connected.`

当你忘记具体项目名时，也可以先说已知部分：`I am looking for a setting related to network details.` 这比硬猜一个不确定的菜单名更好。对方可能会问 `Do you mean DNS, TCP/IP, or Proxies?`，你就可以根据目的继续定位。软件英语的目标不是装作已经全懂，而是能够用准确、可追问的语言把问题缩小。

## 自测

1. 系统设置内的 `Search` 和 Spotlight 的搜索范围有什么不同？
2. `Go Back`、`Cancel`、`change it back` 各自能否恢复已保存的开关值？
3. 你在搜索结果里如何确认进入的是正确页面？
4. 把“在系统设置中选择隐私与安全，然后打开位置服务”写成英文路径句。

1. 系统设置搜索主要找设置页面和选项；Spotlight 搜索范围更广，可能找到 App、文件和建议。
