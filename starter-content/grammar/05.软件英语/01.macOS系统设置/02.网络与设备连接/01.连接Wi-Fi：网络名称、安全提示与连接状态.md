# 连接 Wi-Fi：网络名称、安全提示与连接状态

Wi-Fi 页面的英语不只是“无线网络”几个单词。它同时描述四件事：无线功能是否开启、这台 Mac 是否已经连上网络、当前网络是否有安全提示、列表中的网络和本机过去有什么关系。把这四件事分开读，才能在网络正常、网络受限和网络尚未加入时给出准确描述。

> [!info] 本篇完成后，你应该能做到
>
> - 区分 `Wi-Fi is on`、`Connected`、`Known Networks` 和 `Other Networks`。
> - 看懂 `Weak Security` 警告到底在提示什么。
> - 说清“网络可见”“网络已保存”“网络已连接”三个不同状态。
> - 在不输入密码、不切换网络的前提下完成一次安全的网络状态检查。

## Wi-Fi 页面先回答四个问题

打开 Wi-Fi 后，很多人马上去看列表里有没有熟悉的网络名称。更可靠的顺序是先回答四个问题：无线功能开了吗？这台 Mac 连上了吗？系统有没有发出安全或错误提示？列表中的网络是什么关系？

| 要确认的问题 | 对应的英文线索 | 它真正说明什么 | 不应推出什么 |
| --- | --- | --- | --- |
| Wi-Fi 功能开了吗？ | `On` / `Off`，或开关状态 | 无线网卡功能是否启用 | 一定已经联网 |
| 当前连上了吗？ | `Connected` | Mac 已与一个网络建立连接 | 网络一定能访问所有网站 |
| 有安全提示吗？ | `Weak Security`、锁图标或说明 | 系统发现网络安全配置值得注意 | 信号一定弱或立即断网 |
| 网络是什么关系？ | `Known Networks`、`Other Networks` | 本机是否记住过该网络 | 该网络是不是你自己的 |

最常见的误判是把“Wi-Fi 开关为 On”当成“互联网已可用”。`On` 只说明无线功能打开；真正描述连接结果的是 `Connected`。即使出现 `Connected`，网页仍可能打不开，原因可能在 DNS、代理、VPN、认证门户或网络本身，这些属于后续页面和后续检查。

这张图里 `to join` 很值得背。网络语境的 `join a network` 意味着“加入并尝试建立连接”，它不同于 `connect to a network` 的结果描述。你可以先执行 `join`，但还不能说已经 `connected`；必须等页面给出连接状态或可验证的结果。

## 已知、可见与已连接：三种关系

同一个网络可能同时满足两种关系，也可能只满足一种。理解它们是排查“为什么电脑没有自动连上”的基础。

| 关系 | 英文 | 系统保存了什么 | 现在能否上网 | 常见下一步 |
| --- | --- | --- | --- | --- |
| 可见 | `available` / 列在网络列表中 | 只说明系统当前检测到了信号 | 未知 | 选择网络，必要时输入凭据 |
| 已知 | `known` | 通常保存过网络信息或连接记录 | 未知 | 查看是否自动加入、是否有密码变化 |
| 已连接 | `connected` | 已建立当前连接 | 仍需看实际网络服务 | 打开 Details 检查地址、DNS 或代理 |
| 自动加入 | `automatically join` | 系统会在条件合适时尝试连接 | 未知 | 检查是否被其他网络或策略覆盖 |
| 已断开 | `not connected` / 没有 Connected 状态 | 当前没有这条连接 | 否 | 判断是功能关闭、网络不可见还是认证失败 |

下面两句话的差异很重要：

> `The network is known to this Mac, but it is not currently connected.`
>
> 这台 Mac 认识这个网络，但当前并没有连接。

> `The network is available, but I have not joined it.`
>
> 这个网络可见，但我还没有加入。

第一句多用于“以前连过、现在为什么没自动连接”；第二句多用于“看得到网络、但还没有执行连接”。不要把它们都简化为“有 Wi-Fi”。

## `Weak Security` 到底提醒了什么

`Weak Security` 是安全警告，不是信号质量报告。系统的意思通常是：当前网络使用的安全方式可能过旧，或者保护强度不符合现代推荐标准。它不直接告诉你密码错误、路由器坏了，也不等于 Mac 已被攻击。

| 你看到的内容 | 正确理解 | 下一步可以做什么 | 不要做什么 |
| --- | --- | --- | --- |
| `Weak Security` | 网络的加密或安全配置需要注意 | 询问网络管理员、在可信网络上查看路由器安全设置 | 因为警告就随意修改 Mac 的 DNS 或代理 |
| 锁图标 | 网络通常需要凭据或受保护 | 确认你是否拥有合法密码 | 把锁图标理解为“当前已经安全连接” |
| 信号强度图标 | 无线信号相对强弱 | 若网络不稳定，可移动位置或比较其他网络 | 把它与安全等级混为一谈 |
| `Connected` 加安全警告 | 当前连接存在，但安全配置仍有提示 | 先分开记录“连接状态”和“安全状态” | 说成“网络没有连接” |

向网络管理员描述时，可以说：

> `My Mac is connected to the Wi-Fi network, but System Settings shows a Weak Security warning. Could you check the network security configuration?`

这句话有三个优点：它先确认连接仍存在，再准确引用系统警告，最后把检查目标放在网络配置上。它没有泄露网络名称、密码或设备地址。

> [!warning] 不要把个人网络数据抄进学习笔记
>
> 网络名称、个人热点名称、IP 地址、MAC 地址、路由器地址和密码都属于动态或敏感界面数据。本讲义会保留原图作为本机对照，但不会把这些值写进正文、词汇表、全库搜索或练习答案。练习时请使用 `the current network`、`a known network`、`the selected network` 这类通用表达。

## 连接流程里的动作词

Wi-Fi 页面对同一网络会出现多个动作词。它们的顺序和结果不同。

| 动词或短语 | 操作含义 | 结果如何确认 | 容易混淆的词 |
| --- | --- | --- | --- |
| `turn on` | 打开无线功能 | 开关显示 On | `connect` |
| `choose` | 在列表中选一个网络 | 该行被选中或进入下一步 | `join` |
| `join` | 请求加入网络 | 之后出现 Connected、认证或错误 | `know` |
| `connect to` | 与网络建立连接 | 出现 Connected 或连接状态 | `turn on` |
| `disconnect` | 停止当前连接 | Connected 状态消失或页面确认 | `forget` |
| `forget` | 删除本机保存的网络信息 | 网络不再作为已知网络，之后可能要重新输入凭据 | `disconnect` |
| `show detail` | 查看某一条目的详情 | 打开该网络的详情页面 | `advanced` |

`forget` 是高影响动词。它通常不只是“临时断开”，而可能删除本机保存的连接信息。初学者如果只是想测试网络，不要用 `Forget This Network`；先选择查看详情或暂时断开，并确认能恢复。

## 两个完整操作案例

### 案例一：只读确认当前网络状态

目标：练习区分 Wi-Fi 功能状态、连接状态和安全提示，不改变任何网络配置。

1. 打开 **System Settings**，选择 **Wi-Fi**。
2. 找到 Wi-Fi 开关，判断它是 `On` 还是 `Off`。
3. 找到当前网络所在区域，判断是否有 `Connected`。
4. 检查是否出现安全提示或可见的信号图标，但不记录网络名称。
5. 读出 `Known Networks` 与 `Other Networks` 两个分组标题，解释它们不是“安全”和“不安全”的分类。
6. 用英语汇报：`Wi-Fi is on. This Mac is connected to a network, and I checked the current status without changing any network settings.`

如果没有看到 `Connected`，不要把句子硬说成已连接。可以改成：`Wi-Fi is on, but I do not see a current connection status.` 这是一条正确的观察，不是失败。

### 案例二：查看详情后验证连接仍在

目标：理解 `Details…` 是导航动作，练习完成后返回验证。

1. 在当前网络行旁找到 **Details…**。
2. 点击后先读新页面标题；确认它是当前网络的详情，而不是某个通用网络设置。
3. 只观察分组名称，如地址、DNS、代理或自动加入；不要修改值、不要删除项目。
4. 使用返回按钮回到 Wi-Fi 页面。
5. 再次检查是否仍显示 `Connected`。
6. 用英语说：`I opened the network details to review the connection settings. After going back, I confirmed that the Mac was still connected.`

`After going back` 只描述页面导航；`confirmed that… was still connected` 才说明你做了结果验证。把这两部分分开，报告会更可靠。

## 常见错误与恢复思路

| 现象 | 不要立刻下的结论 | 应该继续读什么 | 安全的下一步 |
| --- | --- | --- | --- |
| Wi-Fi 是 On，但没有 Connected | “互联网坏了” | 是否有当前网络、是否提示认证或不可用 | 先检查可见网络与连接状态 |
| 网络在 Known Networks 里 | “一定会自动连接” | 自动加入规则、当前信号和网络条件 | 只读查看详情，确认保存关系 |
| 有 Weak Security | “信号太弱” | 安全警告文字和网络管理说明 | 向管理员报告安全配置提示 |
| 连上后网页打不开 | “Wi-Fi 页面一定出错” | DNS、代理、VPN、浏览器或认证门户 | 记录 Connected 状态，再按下一层排查 |
| 想重新试一次连接 | “先忘记网络” | `Forget` 的后果和是否知道凭据 | 优先暂时断开或只读检查 |

## 英语表达复习

把下面四句轮流替换关键词，形成可用的网络报告：

```text
Wi-Fi is on, but this Mac is not connected to a network.
This Mac is connected to the selected network.
The network is available, but I have not joined it.
System Settings shows a security warning for the current connection.
```

再加入一个“我没有改动”的安全边界：

> `I only checked the connection status. I did not join, forget, or edit any network.`

这句话对远程求助很有帮助，因为它把已经执行和没有执行的动作都说清楚了。

## 连上 Wi-Fi 后仍不能上网，英语应该怎样说

`Connected` 是重要证据，但不是对所有网络问题的最终判决。连接建立后，域名解析、代理规则、VPN、登录认证页面或网站本身仍可能让访问失败。遇到这种情况，不要把所有现象都描述成“Wi-Fi cannot connect”，因为这会误导下一步排查。

| 你观察到的事实 | 推荐英文 | 它保留了什么边界 |
| --- | --- | --- |
| 页面显示已连接 | `The Mac is connected to Wi-Fi.` | 只确认无线连接存在。 |
| 某个网站打不开 | `A website is not loading even though Wi-Fi is connected.` | 不把网站问题直接归因给 Wi-Fi。 |
| 系统要求完成网络登录 | `The network may require a sign-in page.` | `may require` 表示需要继续确认。 |
| 怀疑名称解析异常 | `I want to check the DNS settings.` | 明确下一步是 DNS，不随意修改。 |
| 怀疑代理影响访问 | `I need to review the proxy configuration.` | 把问题范围缩小到代理规则。 |

一个完整、可交接的报告可以是：

> `Wi-Fi is on and the Mac shows a Connected status. However, a website is not loading. I have not changed the DNS, proxy, or VPN settings yet.`

这句话同时给出已经确认的状态、仍然存在的现象和没有触碰的高影响设置。无论是自己继续查，还是请别人帮助，都会比“我的网坏了”更有效。

## 自测

1. Wi-Fi 为 On、网络为 Known、网络为 Connected 三者分别表示什么？
2. `Weak Security` 为什么不能翻成“弱信号”？
3. `forget a network` 和 `disconnect from a network` 的风险有什么不同？
4. 用英文说出“网络可见，但我还没有加入它”。

<details>
<summary>查看参考答案</summary>

1. On 表示无线功能开启；Known 表示 Mac 保存或认识该网络；Connected 表示当前已经建立连接。
2. 它提示的是网络安全配置，不是无线信号强度。
3. Disconnect 通常停止当前连接；Forget 可能删除已保存的网络信息，之后可能需要重新输入凭据。
4. `The network is available, but I have not joined it.`
